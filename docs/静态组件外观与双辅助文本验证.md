# 静态组件外观与双辅助文本验证

日期：2026-10-30。验证基于main a888fe88，提交前已快进兼容最新main 6e805ddb（PR713），无冲突；
变更仅限静态路线及其公共转换入口的静态分支。

## 行为

- 标题12fp/16vp、字重400。
- 单行列表1–3项自动背板，高32、圆角8、左右内边距12、右值12fp/700。
  三项占满剩余内容高度均匀分布；1/2项以4间距整体贴底；更多项保持原紧凑形式。
- 参考小卡背板126宽；宽卡284宽，左右8安全区，标题左右12。正式产物仍自适应宿主。
- 分割线列表左侧自动编号，沿用Badge样式；先扣编号宽度和间距再核算原字段。编号不进入事实账本。
- 强调主文本左上。secondaryText与bottomText只有一个非空时放左下，两个非空时前者紧随主文、后者左下。
  缺省、null、空白辅助字段视为空；非文字类型拒绝。没有新增SecondaryBody或布局变体。
- 新bottomText参与来源/分组覆盖、修复字段定位、主题保真；可选字段不是删除必要事实的授权。

## 容量边界

背板内边距和列表编号会减少可用文字宽度。原来刚好能单行显示的长值可能需要改用其它已登记组件，
或由既有流程明确处理遗漏；本次没有放宽宽高、字号、来源、分组和Drop授权。
原有长电价三行的测试保留为容量失败回归，短时段版本继续验证共享说明、真实处理入口和Artifact。
试排找不到候选不等于模型不存在其它合法组织方式。本批无基线重跑，不声称质量或完整率提升。
