- 使用同一目录中的 106 个请求，包含 100 个唯一业务输入；两轮逐文件 SHA-256 和业务内容哈希一致。

## 第二层空输出恢复与调用诊断补充验证

后续改动基于模板修复提交 `f2610782db7ed16d97e9fd36d1a565efdd21f743`：

- 第二层生成和第二层编译修复遇到 `MODEL_EMPTY_OUTPUT` 时，在同一物理客户端内允许一次退避重试。
  默认初始退避 1 秒并沿用抖动配置，全局重试关闭时也生效；与全局重试预算取边界，不叠加次数。
  再次为空后保留原有主备/模板回退行为。首层、普通模型、传输错误和截断输出不增加重试预算。
- llmclient 的官方 HTTP 路径把 thinking 配置显式传入，包括 `false` 对应的 `thinking.type=disabled`。
- 每次有效响应在日志和 trace 中记录结束原因、输入/输出/总 token、可用的推理和缓存 token、
  正文及推理文本长度。缺失用量保持未知；新增诊断不记录推理正文或凭据。
  `finish_reason=length` 按既有方案归类为 `MODEL_OUTPUT_TRUNCATED`，不当作可恢复的空输出。
