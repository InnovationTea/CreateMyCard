## 真实模型测试口径

- 使用同一目录中的 106 个请求，包含 100 个唯一业务输入；两轮逐文件 SHA-256 和业务内容哈希一致。
- 使用真实 `deepseek-v4-flash`，temperature 0.7，有效 max_tokens 8192。
  配置中的 thinking=false 未传入 HTTP 请求，两轮均省略该参数。
- 模板开启、产物校验开启；生成层的模型失败重试、校验失败重试、接口重试均关闭。
  模板内部编译修复机制维持原配置。请求并发 4、模型并发上限 6。
- 两轮运行配置仅 trace 和输出目录不同。每个请求本轮只回放一次，没有选择性补跑。
- “命中”表示模板源已经成功编译并进入公共处理器；“模板成功”还要求最终接口成功。
  普通模型回退成功不算模板成功。
- 产物存储使用仓库本地 OBS 适配器；不构成真机渲染或正式 CodeCheck 证据。
