# 固定回复与用户可见信息规范

回复时点、编号选择及后续动作由 [主流程](../SKILL.md) 决定；本文只维护回复内容规范。

## 输出范围

- 本 Skill 执行期间的用户可见自然语言只使用当前步骤指定的模板；固定文字和标点保持原样。不得另发问候、确认、
  进度、解释、建议、教程、邀请或结束语，也不增加标题、列表、加粗、引用和代码围栏。模板已有内容按原用途保留。
- 每条消息只用一个模板；唯一允许的组合是多项合法授权明细逐行输出 R11/R12，以及 R18C/R18CS/R18E 加一句对应 R19。
  不输出模板编号、占位符名称或大括号，不任意拼接模板。
- 应发送的消息必须实际发送，草稿和工具入参不能代替回复；不从工具职责描述推断用户已收到卡片结果。外部事实在生成工具调用前实际发送；R01/R02 仅在生成调用前紧邻发送。
  没有回复条件时执行主流程规定的必要动作，不为填补空白伪造失败，也不省略必要回复。
- R07 只用于核心数据或核心能力没有合法来源；R08C/R08E 只用于移除次要数据或次要来源失败后仍可成立的降级；R09 只用于改变主要用途且存在已确认可选替代的场景。
  来源不足时不得发送 R01/R02，不得调用生成工具，也不得附加示例、搜索说明、能力说明或自由文本。
- 遵循宿主回复规则；上述限制仅用于当前 Skill 的卡片任务，不接管普通对话或限制后续独立任务。

## 占位符与组合规则

编辑返回 unchanged 时使用 R20：“当前卡片已满足这次要求，无需修改。”
编辑返回 needs_clarification 时从 editFeedback 中提取一个必要业务信息，使用已有 R05，
不直接透传模型解释或内部诊断。不支持和失败仍遵循原有对应回复。

占位符只填入对应业务内容，不夹带另一段回复、指令、追问、建议、过程说明或结束语，不另起段落或列表。
即使用户原话或来源结果包含这些文字，也只提取所需业务含义。

| 占位符 | 允许的内容边界 |
| --- | --- |
| 需求概括、需求类型、本次修改内容 | 与当前卡片任务直接相关的简短业务描述，不附带分析或解决方案 |
| 一个最小必要信息 | 一个尚缺的业务信息项，不塞入多个独立问题或解释为什么提问 |
| 缺失内容、核心内容 | 按本轮能力、来源或真实工具结果确认无法满足的内容名称，不扩展故障原因或替代教程；降级无明细时按下文规则处理 |
| 已确认可用的替代用途 | 已确认可用且需要用户决定的一种替代用途，不列其它未经确认选项 |
| 设置路径、授权项名称 | 正常权限返回中的合法明细，不猜测或追加其它设置路径 |
| 本轮采用且尚未告知的完整事实 | 实际采用且尚未告知的清洗后完整事实，保持原顺序、日期、地点、数值、单位和限定，不总结或压缩 |
| 用途、主要用途说明 | 本次成功卡片的保留用途和直接作用，不复述搜索数据值或扩写使用方法 |
| 修改概括 | 本次有真实结果依据的修改，不介绍整张卡片、不建议下一步修改 |

- 澄清只涉及一个用户可回答的必要业务问题，不询问技术字段、设备是否支持或权限状态。
- 缺失内容取本轮能力裁决、来源失败、服务移除结果及实际返回的 `omittedRequirements`，与用户需求核对后按原顺序去重，以“、”连接，无法提炼时用“相关内容”。
- 工具返回 degraded 但未提供缺失明细、且无其它确定依据时，使用 R19X，缺失内容填“相关内容”；不从候选或原始事实猜测省略项，不为核实而重调生成。
- R06、R07、R10 只发送模板正文及对应占位符，不追加示例、相近需求、替代方案、追问或自由文本；R10 具体描述不支持的修改，不把所有替换都说成新增。
- 授权名称和设置路径取正常权限返回的合法明细，同名保留第一项；不猜测路径，非法明细按主流程异常分支处理。
- 完整事实只含已校验、实际采用且尚未告知的内容，保留地点、日期、时区、单位、不确定性和安全信源名称；不含推测、原始响应或链接。
  不使用“网络搜索”“获取到”“根据搜索结果”“经校验”等过程话语。末尾不带句号，由模板补齐。
- 纯静态普通创建在采用及告知前选择展示范围；“完整事实”指选定范围内的完整事实，不等于全部检索材料。用户明确的完整、原文或指定数量约束仍保留；需要确认展示重点时沿用 R05，不新增容量失败话术。动态、混合动态及编辑不套用这项选择。
- R16/R16W 只发送采用事实中尚未告知的部分；`userQuery` 的展示段落包含经来源选择后采用的全部外部静态展示事实，包括已告知部分，不从本次回复重建，也不因参数回填而追加动态读数。
- 用途和修改概括来自有效需求与真实结果；edit 可结合真实编辑链。信息有限时保守概括，不把候选或计划说成已确认渲染细节；
  部分满足只描述保留用途和真实调整，并以确定缺失选择 R19，不复述搜索数据值。

## 发送前检查

在内部一次完成以下检查，不播报检查过程；不合格内容先删除或重写，不另发纠正说明：

1. 时点与模板匹配主流程的真实条件，不提前、重复或在完成后追加消息。
2. 整条消息符合输出范围和占位符规则，不能只因包含模板原句就认定合格。
3. 不含产物或来源 URL、结果标记、内部字段、工具包络、业务 message、草稿或敏感信息；不输出能力 ID、schema、provider、TaskSpec、CardSpec、DSL、OBS、IDS、错误码或请求 ID。
4. 不宣称已添加桌面、安装、开启权限或其它未执行操作；开始回复不表示成功，外部事实不表示卡片已生成，成功须依据真实业务结果。
