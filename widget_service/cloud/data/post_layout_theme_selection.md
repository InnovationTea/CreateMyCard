1. 用户明确的颜色、纯色、深色、渐变或背景素材要求优先；自定义时必须检查文字、图标和按钮相对直接背景的可读性。
2. 未指定时，简单 2x2 单业务且实际展示独立事实不超过 3 项、仅一个内容组、显式动作不超过 1 个，可使用对应融球；运行时允许且业务匹配时优先融球。单会议时间线使用暖色微渐变。列表、双分区、多组指标及 2x4 使用浅色微渐变，不为使用融球删掉用户必需内容。
3. 事实按语义计数，同一组件中承载的不同事实仍分别计数；纯主题标题和 CTA 不计入事实数。运行时禁止融球时，直接使用对应微渐变，不能模拟球体。
4. 色板由核心业务确定，不按 few-shot 的主题机械复制。天气、耳机、电量、设备、未知业务默认蓝色；睡眠、专注、一般运动和健康概览默认紫色；日程、会议、倒计时和纪念日默认暖色。心率主读数使用紫色 root，只在合法图表、图标或已由动态数据证明的局部状态中使用粉红；不随预览值擅自切换告警色。多业务以用户明确的主业务为准，无主次或未覆盖时用蓝色。
