# 对比组件

## 总表
| 组件 | 适用条件 | 承载内容 | 使用边界 |
|---|---|---|---|
| ComparisonGroup | 两到三个对象按相近维度比较 | items[].primaryText、secondaryText、details | 仅2x4，必须带SingleLineTitle |

## ComparisonGroup
### 选择条件
对象具有可比较的读数、条件或方案；各栏对象与字段层级一致。长叙述优先全宽列表。
ComparisonGroup仅规划带SingleLineTitle标题的2或3项；四个对象改用完整承载的带标题列表。
### 语义字段
items为2–3项；primaryText必填，secondaryText可选，details为可选1–2条辅助文字。
对象名称和数值须在各自栏内可读，不用其它栏或共同标题代替本栏名称。
### Runtime规则
使用等宽横排背板、8vp栏间距。primaryText保留完整文字换行和容量检查，
secondaryText最多两行，超出后在第二行显示省略号。
所有背板保持8vp内边距、12vp圆角、固定文字层级和等高；辅助字段仍放不下时精简Plan表达，不能缩字。
### 示例
```genui
["body","ComparisonGroup",{"items":[{"primaryText":"128元/月","secondaryText":"甲方案","details":["30GB"]},{"primaryText":"159元/月","secondaryText":"乙方案","details":["60GB"]}]}]
```
