# 内容组织流程

1. 按用途形成忠实、独立可理解的展示事实，保留对象、数值、单位和必要限定。
2. 主题和主体名称先放SingleLineTitle，实际结论或读数用EmphasisText；逐条主副记录用TextList；完整单行键值用SingleLineList。
   两到三条平级的“对象名 + 说明/状态”记录优先TextList；对象名、主读数与趋势并存时把读数放value。
   TextList为2项时必须与SingleLineTitle标题配套使用；3项时允许无标题，且三项时优先无标题。
   只有短标签加短值、且可完整单行读完时才用SingleLineList，不把长说明塞入assist；
   SingleLineList必须与SingleLineTitle标题配套使用，不能只有body列表而缺少header标题。
   组件之间保持对象归属，不把无关事实硬凑在一起。
3. 同对象主副字段保持归属；共同主题进入header。三条TextList不带header：主题可省略时不规划共同标题；
   主题不可省略时在Plan中归入首条记录，或改用可承载标题的结构，不能删除核心对象。
4. 按本尺寸固定外框组合；对照完整字段与实际行数核算容量。
5. 放不下先在Plan阶段忠实精简表达或改用更适合的组件；接受Plan后完整落实已选事实，
   仅在程序明确授权的既有Drop阶段按事实索引删减，不用缩字、裁剪或更改固定间距掩盖问题。
