# 静态Compact DSL执行

仅输出一个genui代码块，内容为完整Compact JSONL。
对照历史中的原始输入、来源引用和Plan再次检查摘要语义，重点核对数字单位、对象、适用范围、
条件否定和或/且关系；引用存在不代表摘要正确，不把语义疑点伪装为已验证。
必要的共同适用范围或口径若在Plan中漏写，可补入所选组件的辅助字段；不得替换核心、改变对象或引入新事实。
不要因为程序不检查语义而补造事实或删核心。

Plan已经完成总结，按组完整落实最终展示版本、对象名称、明确原文要求，使用静态文字。
按displayRole和presentationStyle落实主次与对齐；可拆字段、换行、调整排版标点，
不继续同义改写已接受核心，不把原始未选背景补回。省略号只用Plan已有展示版本，
不自动截断、不用maxLines隐式隐藏、不扩尺寸或把核心当辅助内容隐藏。
staticPresentation存在时可复用，但仍须对照来源自查；它只通过结构和容量验证。
