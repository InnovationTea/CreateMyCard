# 静态Compact DSL执行

仅输出一个genui代码块，内容为完整Compact JSONL。
在本次既有生成推理内对照历史中的原始输入、来源引用和Plan再次检查摘要语义，
重点检查数字单位、对象、适用范围、条件否定和或/且关系；引用存在不代表摘要正确。
必要的共同适用范围或口径若在Plan中漏写，可补入简短共享说明；不得替换核心、改变对象或引入新事实。
不要因为程序不检查语义而补造事实或删核心，语义疑点不得伪装成已验证。

Plan已经完成总结，按组完整落实最终展示版本、明确原文要求和动作，不添加动态绑定。
可以拆分字段、换行、调整排版标点，不继续同义改写已接受核心，不把原始未选背景补回。
staticPresentation存在时可复用，但仍须对照来源自查；它只通过结构和容量验证。

正文只用ContentBlock、RecordList、ComparisonGroup；旧组件仅必要标题、共享说明和动作。
无动作使用S-static-content/W-static-content；列表/对比最多三项，属性表最多六项。
若已接受 Plan 只有一个 Action、至多一个明确标题事实、没有正文/dataId 展示事实，使用
`S-title-content-action` 的 `title-action` 变体，直接输出 `[title, action]`。不得添加任何正文来填满卡片；
action 必须是 PillButton 并完整复制候选 handler。只要 Plan 有正文或 dataId 展示事实，不能使用该变体。
优先全宽ContentBlock或plain RecordList；短键值用属性表，短且等权对比才用ComparisonGroup。
空间不足先去装饰、切换合法组件、把侧栏移本条全宽，再整项省略无保护should；must完整保留。
省略号使用Plan已有版本，不再自动截断；不能任意缩字、隐式裁切、扩尺寸或把核心搬note。
无素材不补emoji、网络图或猜测资源。颜色由后置主题处理。

按Plan的displayRole落实名称、主值、正文与辅助文字层级；多对象记录突出名称，短值独立对齐。
遵循presentationStyle的结构意图；RecordList能承载时不要降成无层级的整句属性表。
属性行没有标签可仅填value，不补“信息”。同一对象必要的单位、频率和条件仍须完整显示。

对象名称按Plan.contentGroups.identity落实在本对象可见内容内；不是内部ID，也不能仅放共享note。
相同对象允许字段换序、增加解释性标签，仍须完整保留原值及归属；不能用别的对象补覆盖。
S-static-content/W-static-content可用variant:"compact"将区块间距从6缩至4；默认flow保持6。
无label属性默认12字号、16行高；静态说明默认12字号、14行高；容量不足可用下方登记档位。
颜色继续由后置主题按既有蓝、紫、暖色处理，使用标题/主值/正文/辅助的清晰层级。

容量紧张时可将对象短名称与完整正文合入同一无标签value，避免名称额外占行；字段仍归本对象。
相同主体、周期与口径可在明确共同上下文只写一次。必要适用人群、强度、范围、例外和或/且关系
必须保留，不能登记omittedContents后视为允许删除；冗余措辞的等义精简不要误报为信息损失。

静态正文与辅助文字可用fontSize:12|11|10三个档位，10为硬下限；不接受其它数值。
ContentBlock、RecordList、ComparisonGroup和静态SecondaryBody支持该字段；默认省略即12。
先尝试12字号的清楚结构，再尝试11、10保留完整信息，最后才考虑省略should。
标题、记录名称和对比主值保留原有层级字号；行高、换行和完整文字容量由共同合同按所选档位计算。
不要直接统一降到10，不允许隐式截断、裁切、连续缩放或删除必要条件；后置主题不再更改已选字号。

静态SingleLineTitle是完整单行标题，12字号、16行高；超宽应在Plan中拆出短标题与日期/口径说明，
不能依靠裁切、maxLines隐藏或缩小标题。主体、必要范围与日期口径必须继续可见。
属性行valueRole:body|value，默认body左对齐，只有模型明确声明的短读数用value右对齐。
标题或label已经承载对象名时，不在value重复；同一对象保留统一名称，不用不同简称制造重复。
整卡主体与共同口径须有可见位置，条目优先按用户的时间/分组关系组织；should不要机械追加到末尾。
不要把单个组件最多3条误当整卡只能3条；可在Plan中选择合法的完整属性表，无法完整承载则如实失败。
