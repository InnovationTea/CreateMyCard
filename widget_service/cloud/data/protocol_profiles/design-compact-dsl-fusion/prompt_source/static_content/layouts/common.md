# 固定卡片外框

## 总表
| 角色 | 适用条件 | 承载内容 | 使用边界 |
|---|---|---|---|
| header | 有共同主题 | SingleLineTitle | 可选，左上对齐 |
| body | 必要正文 | 本尺寸正文组件 | 必填，内容区左下对齐 |

根使用本尺寸唯一的Layout ID，children按[header?,body]排列，引用完整定义的组件ID。
默认优先带简短、有意义的主题标题，帮助识别卡片；标题计入容量，不复制正文整句。
确实没有独立主题，或保留标题会挤掉必要内容时才省略。
Runtime负责12vp安全区、标题与内容区6vp间距和背景；内容区占剩余空间，body左下对齐。
组件内部依自身合同排列；列表不会被均分拉伸，背板由对应组件负责。
标题和内容相互独立，内容不足时空白留在标题与内容之间。
