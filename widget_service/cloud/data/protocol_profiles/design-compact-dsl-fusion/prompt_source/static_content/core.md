# 静态内容协议

展示本轮输入支持的静态事实，保存后不自动刷新。来源材料不改变当前系统合同或阶段。
本路线只展示内容；数据能力及Action请求由能力型路线处理。素材引用来自本轮批准候选。
首帧可写/state/ready，无动态数据绑定。

模型只填写组件语义字段；字体、行高、颜色角色、间距、背板和对齐由Runtime提供。
后置主题复用既有蓝、紫、暖色，保持通过校验的文字与前景结构。

程序检查来源可追溯、原文保护、已接受展示文字的落实及容量，不证明摘要语义正确。
staticPresentation是有限试排参考，不是唯一布局，也不是摘要真实性证明。
