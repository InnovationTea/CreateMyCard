## 9.1 2x2 固定语义布局

画布和安全区遵循公共布局合同。普通布局 root 使用 `padding:12`，仅 `S-dual-info` 使用 `padding:8`。
带标题布局使用单行 `SingleLineTitle`；其内部高度由组件 Runtime 固定，标题至首个内容区默认间距为
`6vp`，三行正文等密集内容可使用 `4vp`。动作按钮固定高 `36vp`。布局只规定一级区域关系，
内容组件按对应组件与组合规则展开。

正文和主辅区域优先使用 `matchParent`、`layoutWeight` 承接扣除固定设计量后的剩余空间，不在 DSL 中
手算或写入派生高度。单业务内容按完整文字实际高度分配主辅空间，保留标题—内容—支撑/动作关系；
各正式布局声明的顶部、底部或居中对齐优先于通用密度建议，多个事实连续纵排，动作保持沉底。
普通成对读数作为 `S-title-content` 内的一个同级信息组，可用等宽短数值列；各列压力不成立时
改为纵排，不套用双环布局。两个数值之外另有更新时间等支撑时，使用 `S-title-dual-content`。

以下 DSL 只演示布局结构。静态文案、颜色、素材和事件用于标明槽位；实际生成必须替换为 TaskSpec 中的
真实内容与候选，不得照抄示例业务值。
区域宽高使用 `matchParent` 或 `layoutWeight`；同级区域等分用权重1，主辅区域按内容关系分配权重。
固定 padding、间距、按钮、图形及文字行高不随区域放大；具体容量由运行时布局合同验算。

### `S-center`（核心居中）

- 适用：一个无需标题即可理解的 Data Display，无动作。
- 尺寸与闭合：唯一内容区使用安全区全部剩余空间。
- 对齐：内容双轴居中。
- 回退：内容需要对象名、标题或独立说明时改用带标题布局。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"alignItems":"center","justifyContent":"center","backgroundColor":"#FFF1F6FE"},["value"]]
["value","<唯一内容槽>",{"width":"matchParent","height":"matchParent"}]
```

### `S-title-content`（标题单内容）

- 适用：标题 + 一个主体内容组，无动作、无独立支撑区。
- 尺寸与闭合：标题和固定间距之外的剩余空间全部交给主体内容区。
- 对齐：主体左对齐并贴内容区底端。
- 回退：存在独立支撑事实时改用 `S-title-dual-content`；存在动作时改用带动作布局。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":6,"backgroundColor":"#FFF1F6FE"},["header","content"]]
["header","<标题槽>",{}]
["content","<主体内容槽>",{"width":"matchParent","alignItems":"start","justifyContent":"end","layoutWeight":1}]
```

### `S-title-dual-content`（标题双内容）

- 适用：同一对象的主信息 + 独立支撑信息，无动作。
- 尺寸与闭合：主内容与支撑共同使用标题以下的剩余空间；两区可等权，也可按实际完整行高分配权重。
- 对齐：主信息左上，支撑信息左下。
- 回退：主辅必须连续阅读时合并为单内容；两个区域属于不同对象时改用 `S-dual-info`。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":6,"backgroundColor":"#FFF1F6FE"},["header","body"]]
["header","<标题槽>",{}]
["body","Column",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["primary","details"]]
["primary","<主信息槽>",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1}]
["details","<独立支撑信息槽>",{"width":"matchParent","alignItems":"start","justifyContent":"end","layoutWeight":1}]
```

### `S-quad-content`（内容四宫格）

- 适用：四个同级、可独立识别且能在单格完整表达的短模块，无标题、无动作。
- 尺寸与闭合：四格均为 `59×59vp`，横纵间距均为 `8vp`。
- 实现：使用 Row/Column 展开固定 `2×2` 几何，不输出 Grid。
- 对齐：每个内容组件直接占据一个 `59×59vp` 槽，不额外增加会改变组件测量结果的包裹层。
- 回退：任一模块无法完整放入单格时改选其它布局，不留空格或拆分字段凑格。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":8,"backgroundColor":"#FFF1F6FE"},["row_one","row_two"]]
["row_one","Row",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["cell_a","cell_b"]]
["row_two","Row",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["cell_c","cell_d"]]
["cell_a","<同级内容槽>",{"width":59,"height":59}]
["cell_b","<同级内容槽>",{"width":59,"height":59}]
["cell_c","<同级内容槽>",{"width":59,"height":59}]
["cell_d","<同级内容槽>",{"width":59,"height":59}]
```

### `S-title-content-action`（标题内容单按钮）

- 适用：标题 + 一个主体内容组 + 一个动作。
- 尺寸与闭合：标题按 Recipe 实际单行高度参与预算，标题后保留 `6vp`、正文到动作保留 `8vp`，
  动作高 `36vp`。body 和正文使用 `layoutWeight` 承接对应剩余空间，不在 DSL 中重复写入派生高度。
- 三行正文：root 改用 `itemMargin:4`，body 和正文继续使用权重；标题、正文至动作的 `8vp` 间距及动作高度不变。完整行高无法闭合时更换布局或减少可选信息，不写固定正文高度掩盖问题。
- 对齐：正文左上，底部整宽动作沉底。
- 回退：没有动作时改用 `S-title-content`，不保留动作槽及其间距。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":6,"backgroundColor":"#FFF1F6FE"},["header","body"]]
["header","<标题槽>",{}]
["body","Column",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["content","action_area"]]
["content","<主体内容槽>",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1}]
["action_area","<底部动作槽>",{"width":"matchParent","height":36}]
```

### `S-title-primary-secondary-action`（标题主次内容单按钮）

- 适用：标题 + 紧密关联的主、次内容 + 一个动作。
- 尺寸与闭合：标题至内容组默认 `6vp`，主次间距 `2vp`，正文至动作间距 `8vp`；body 和正文使用权重承接剩余空间。需要三行正文时，与 `S-title-content-action` 一样将标题间距成组改为 `4vp`，不混用两套间距，也不写派生高度。
- 对齐：主次内容从左上连续排列，动作沉底。
- 回退：没有动作时按内容关系改用 `S-title-content` 或 `S-title-dual-content`。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":6,"backgroundColor":"#FFF1F6FE"},["header","body"]]
["header","<标题槽>",{}]
["body","Column",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["content","action_area"]]
["content","Column",{"width":"matchParent","itemMargin":2,"alignItems":"start","justifyContent":"start","layoutWeight":1},["primary","secondary"]]
["primary","<主内容槽>",{}]
["secondary","<紧密关联的次内容槽>",{}]
["action_area","<底部动作槽>",{"width":"matchParent","height":36}]
```

### `S-title-dual-column-action`（标题双列内容可选按钮）

- 适用：同一对象内两个具备可靠比例语义的同级指标。
- 内容区：单行 SingleLineTitle 下放两个等权环形指标列，列间距 `8vp`；每列一个环和自己的值、标签，环形组件尺寸按组件容量合同确定。
- 动作区：可选底部整宽动作；存在时内容至动作间距 `8vp`，不存在时同时删除动作槽和间距。
- 回退：普通数值、文字、状态、无可靠 total 或压力预算失败时改用纵向标签—值结构。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":6,"backgroundColor":"#FFF1F6FE"},["header","metrics"]]
["header","<标题槽>",{}]
["metrics","Row",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["metric_a_slot","metric_b_slot"]]
["metric_a_slot","Column",{"layoutWeight":1,"height":"matchParent","alignItems":"center","justifyContent":"center"},["metric_a"]]
["metric_b_slot","Column",{"layoutWeight":1,"height":"matchParent","alignItems":"center","justifyContent":"center"},["metric_b"]]
["metric_a","<同级比例指标>",{}]
["metric_b","<同级比例指标>",{}]
```

### `S-title-anchor`（标题锚点内容）

- 定位：与底部文字动作布局同级，不是 `PillButton` 放不下后的下位回退。
- 适用：只有一个显式动作，存在与动作语义严格匹配的 SVG，用户未要求卡面显示动作文字，并且内容具有
  “主内容 + 左下支撑信息”的关系。存在至少三项必须展示的信息、整宽文字动作会压缩正文时优先使用。
- 尺寸与闭合：标题后为主内容区和底部锚点行。普通单行支撑使用约 `40vp` 的底栏；三个纵向
  `NumericRatioStack` 固定需要 `56vp`，此时主内容区承接其余空间。两种变体都保留 `8vp` 区域间距。
- 对齐：主内容左上；支撑信息位于左下；右下固定 `40×40vp` 槽内居中放置 `CircleButton`。不能为了统一
  底栏高度把纵向三项占比改成另一种构图。
- 改选：缺少准确图标、动作需要文字解释、用户明确要求按钮文案或操作风险需要文字确认时，改用底部
  文字动作布局。不能先固定 `PillButton`，再把独立事实拼成普通正文或取消间距来腾出按钮空间。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":6,"backgroundColor":"#FFF1F6FE"},["header","body"]]
["header","<标题槽>",{}]
["body","Column",{"width":"matchParent","itemMargin":8,"layoutWeight":1},["content","bottom"]]
["content","<主内容槽>",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1}]
["bottom","Row",{"width":"matchParent","itemMargin":8,"alignItems":"bottom","flexShrink":0},["support","action_slot"]]
["support","<左下支撑信息槽>",{"layoutWeight":1}]
["action_slot","Stack",{"width":40,"height":40,"alignContent":"center"},["action"]]
["action","<右下图标动作>",{}]
```

左下支撑为纵向三项 `NumericRatioStack` 时，使用以下容量变体；其它结构不变：

```genui
["content","<主内容槽>",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1}]
["bottom","Row",{"width":"matchParent","height":56,"itemMargin":8,"alignItems":"bottom"},["ratio_support","action_slot"]]
["ratio_support","NumericRatioStack",{"direction":"column","width":78,"height":56}]
["action_slot","Stack",{"width":40,"height":40,"alignContent":"center"},["action"]]
["action","<右下图标动作>",{}]
```

### `S-content-dual-action`（紧凑内容双按钮）

- 适用：单业务紧凑信息 + 两个明确动作。
- 尺寸与闭合：两个动作固定高 `36vp`，紧凑内容使用 `layoutWeight` 承接剩余空间，不额外增加标题或
  其它一级区域。
- 对齐：内容左上；两个整宽动作依次沉底。
- 限制：无 SingleLineTitle；动作缺少时改选单动作或无动作布局。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"borderRadius":20,"clip":true,"itemMargin":8,"backgroundColor":"#FFF6F2FF"},["content","action_one","action_two"]]
["content","<紧凑主体内容槽>",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1}]
["action_one","<第一底部动作槽>",{"width":"matchParent","height":36}]
["action_two","<第二底部动作槽>",{"width":"matchParent","height":36}]
```

### `S-dual-info`（双信息块）

- 适用：恰好两个独立对象，无独立动作槽。
- 尺寸与闭合：root `padding:8`；上下两个固定 `InfoBlock` 槽等权撑满，间距 `8vp`。固定槽容量仍由运行时合同校验。
- 槽位：每个背板使用一个 `InfoBlock`，最多承载两行主辅信息，可选一个右侧 `20×20vp` visual；无 visual 时文字组在背板内垂直居中。
- 对齐：有 visual 时按 `InfoBlock` 组件合同排列文字组与 visual；两个背板使用同一卡片色板。
- 限制：不增加总标题、第三个区域或独立按钮；`InfoBlock` 及其内部组件均不支持事件。存在必须保留的显式动作时改选可承载动作的布局，不能静默删除动作。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":8,"borderRadius":20,"clip":true,"itemMargin":8,"backgroundColor":"#FFF1F6FE"},["zone_a","zone_b"]]
["zone_a","<独立信息块槽>",{"width":"matchParent","layoutWeight":1}]
["zone_b","<独立信息块槽>",{"width":"matchParent","layoutWeight":1}]
```

ProgressCircle、EventCard、倒计时和其它内容预设只能进入所属内容槽，不改变以上一级几何。容量不足时先删除
`shouldKeep`，再改选能承载全部 `mustKeep` 的正式布局；不得跨布局拼接区域。
