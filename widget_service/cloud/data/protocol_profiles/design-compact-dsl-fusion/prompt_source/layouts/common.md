# 布局预算

<!-- prompt:height-gate -->
## 容量门禁

所选语义模板和组件的最小占用必须成立。纵向按真实子项高度加固定间距，横向按各列完整标签、值和单位计算；容器不能按零高度，按钮也不能按零高度。负预算时先重组同对象信息、改合法组件或完整布局，不缩字号、压按钮、改模板间距或裁切。
<!-- /prompt:height-gate -->

<!-- prompt:canvas-heading -->
# 八、画布与布局预算
<!-- /prompt:canvas-heading -->

<!-- prompt:canvas-budget -->
## 参考画布

| 尺寸 | 参考画布 | 安全内容区 |
|---|---|---|
| 2x2 普通布局 | 150×150vp，四边12vp | 126×126vp |
| 2x2 S-dual-info | 150×150vp，四边8vp | 134×134vp |
| 2x4 | 300×150vp，四边12vp | 276×126vp |

这些数值用于选型和压力核算，不填写几何 Props，不代表机型。模板处理实际宿主扩展，新增空间进入正文及背板，不放大字号、按钮、图标、圆环或组内间距。
先扣标题实际高度、动作、内边距和布局固定间距，再核对剩余内容；所有后代行高和换行都计入。弹性内容不等于无限空间；不能把含按钮的整父区高度又全部分给正文。
稀疏内容保持所选模板的对齐，密集内容紧凑连续，动作锚定所属区底部；不加空节点或拉开数值与单位填空间。文本或点击区压力核算后至少留4vp余量，不依赖宿主更大消除超预算。
<!-- /prompt:canvas-budget -->

<!-- prompt:surface-budget -->
背板仅使用已登记的表面；不叠加边框、阴影或无职责容器。容量不足时可省略未要求的装饰，不能删必要事实或动作；保留最小充分内容，重选能闭合的同尺寸合法结构。
<!-- /prompt:surface-budget -->

<!-- prompt:routing -->
# 九、固定布局路由

每卡一个正式父布局。按信息关系、直属动作及实际容量选择尺寸布局表中的结构；Plan.layoutHints 是偏好，不突破槽位约束。固定槽必须由真实模块填满，可选角色缺失时选允许省略该角色的完整结构，不补空槽或重复项。
<!-- /prompt:routing -->

<!-- prompt:layout-check -->
提交前检查：父布局与子布局兼容，children 数量/类型/顺序正确，完整信息与动作仍归属正确对象，每区独立通过宽高压力检查。改变结构时重新核对所有受影响角色，不能跨布局拼槽。
<!-- /prompt:layout-check -->
