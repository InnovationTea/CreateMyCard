## 9.2 2x4 固定语义布局

### 三层布局模型

2x4 布局按三层决定：

1. **整卡安全区**：root 使用 `padding:12`，只建立一次安全边距。
2. **一级布局**：从 `W-top-bottom`、`W-split-panels`、`W-content-side-slots`、
   `W-four-slots` 中选一个，决定整卡区域数量与关系。
3. **父内容区子布局**：`W-split-panels` 每侧选择一个 Sub-118；
   `W-content-side-slots` 的完整内容区选择一个 Sub-140。

`Sub-118` 与 `Sub-140` 是稳定的子布局名称，不是当前物理宽度，也不是可输出的组件类型。
当前 Compact DSL 使用 `matchParent`、`layoutWeight`、`Row`、`Column` 和 `Stack`
表达同样的模块关系；不把旧 JSX 文档中由画布导出的宽高抄入 DSL。

### 选择顺序与语义分组

1. 先按业务对象和共同任务归组事实，再把直接服务该对象的 Action 归入同组。
2. 按一个整宽语义组、两个完整内容区、一个内容区加两个固定槽、四个同级槽的区别选择一级布局。
3. 完成组件选择后，再按内容角色、局部标题和 Action 选择 Sub-118/Sub-140。
4. 根据子布局生成 Compact DSL，最后检查标题、组件最小高度、间距、动作位置和文字压力。

同组的局部标题、主信息和辅助信息保持在同一连续父区域。Action 可进入所属内容区的
`PillButton`，或在当前一级布局已登记的固定槽中使用 `CardButton`；移动视觉位置不改变动作归属。
两个独立业务各有一个直属 Action，且两侧均可使用 Sub-118-D 时，选择 `W-split-panels`，
不把两个动作集中到一个固定槽列。两个 Action 共同服务一个完整内容区时，才使用
`W-content-side-slots` 的双 `CardButton`。

子布局中的“内容”指一个可辨认的语义角色，不按字段数量计数。一个组件内的多个 `items`
仍是一个内容；紧密的 hero + support 可由内层 `Column` 组成一个连续内容组，但不得用包装层
把两个无关业务伪装成一个内容。`Row/Column/Stack` 只负责布局，不增加业务内容数。

### 通用 Compact DSL 规则

- 左右一级区域使用等权 `layoutWeight`，间距 `12vp`；固定双槽和四槽也使用等权分配和 `12vp` 间距。
- Sub-118 内纵向主要角色使用 `6vp` 间距；Sub-140 使用 `8vp`；hero 与紧密 support 的组内间距为 `2vp`。
- 需要居中、左上、左下或底部动作时，由组件外层布局容器表达；不向业务组件增加未公开 Props。
- 有底部动作时，中间内容区使用 `layoutWeight:1`，动作使用 Runtime 固定高度；不用 `spaceBetween`
  替代登记的固定间距。
- `InfoBlock` 只进入 `W-content-side-slots` 与 `W-four-slots` 的固定信息槽，不进入 Sub-118/Sub-140。
- 以下骨架中的 `<...>` 是本轮真实组件、文案、数据或事件的抽象占位，不是可输出的 DSL 组件名或硬编码值。

### `W-top-bottom`（上下双区）

- 适用：一个语义组的主体与同级属性明细形成整宽上下关系，或同一任务的密集记录列表。
- 区域：可选整卡 `SingleLineTitle`、必选主体和必选明细；全部左对齐。无稳定标题时删除标题及其相邻间距。
- 明细：根据语义使用 `TextBlock`、`TopTextBottomValue` 或 `SummaryList`；不在明细区使用 `InfoBlock` 或 `CardButton`。
- 动作：不增加共享按钮。真实只读列表可把详情事件绑定在所属列表整体，不串联副作用动作。

主体与明细只从以下三种高度关系中选择，不按业务名称定义额外“内容预设”：

| 内容关系 | 弹性策略 | 对齐 |
|---|---|---|
| 紧密连续 | 主体自然高度，明细承接剩余高度 | 两者左上对齐 |
| 底部结论 | 主体承接剩余高度，明细使用自然高度 | 主体左上，明细稳定落在底部 |
| 同类同级 | 两个支持伸展的模块等权分配剩余高度 | 各自左上对齐 |

紧密连续：

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"itemMargin":6,"alignItems":"start","justifyContent":"start"},["title","body"]]
["title","SingleLineTitle",{"title":"<真实卡级标题>","fontSize":12,"width":"matchParent"}]
["body","Column",{"width":"matchParent","itemMargin":8,"alignItems":"start","justifyContent":"start","layoutWeight":1},["primary","details"]]
["primary","Column",{"width":"matchParent","alignItems":"start","justifyContent":"start","flexShrink":0},["primary_content"]]
["details","Column",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1},["details_content"]]
["primary_content","<主体组件>",{}]
["details_content","<明细组件>",{}]
```

底部结论：

```genui
["body","Column",{"width":"matchParent","itemMargin":8,"alignItems":"start","justifyContent":"start","layoutWeight":1},["primary","details"]]
["primary","Column",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1},["<主体组件 id>"]]
["details","Column",{"width":"matchParent","alignItems":"start","justifyContent":"start","flexShrink":0},["<明细组件 id>"]]
```

同类同级：

```genui
["body","Column",{"width":"matchParent","itemMargin":8,"alignItems":"start","justifyContent":"start","layoutWeight":1},["primary","details"]]
["primary","Column",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1},["<主体组件 id>"]]
["details","Column",{"width":"matchParent","alignItems":"start","justifyContent":"start","layoutWeight":1},["<明细组件 id>"]]
```

密集列表先保留每条记录的完整时间标识和属性，使用父槽全部可用宽度并按完整文本自然换行。
取消重复标题和可选视觉后仍无法通过容量校验时，不删除必要字段交付。

### `W-split-panels`（左右双区）

- 适用：两个可独立阅读的完整信息区，或同一主题中已形成的“核心结论 + 属性明细”。
- 外层：无公共标题；左右父区等权，间距 `12vp`；每区使用当前 2x4 内容背板、`borderRadius:16`、
  `clip:true` 和 `padding:8`，内容使用所属 Sub-118。背板不向子布局内部再嵌套。
- 动作：每侧至多一个直属 `PillButton`，只绑定按钮，不绑定父背板。
- 限制：无公共内容行、公共按钮、背板外动作或第三业务；Sub-118 内不使用 `InfoBlock`。

```genui
["root","Row",{"width":"matchParent","height":"matchParent","padding":12,"itemMargin":12,"alignItems":"center","justifyContent":"start"},["panel_a","panel_b"]]
["panel_a","Column",{"width":"matchParent","height":"matchParent","padding":8,"borderRadius":16,"clip":true,"backgroundColor":"#99FFFFFF","layoutWeight":1},["sub_a"]]
["panel_b","Column",{"width":"matchParent","height":"matchParent","padding":8,"borderRadius":16,"clip":true,"backgroundColor":"#99FFFFFF","layoutWeight":1},["sub_b"]]
["sub_a","<Sub-118 子布局>",{}]
["sub_b","<Sub-118 子布局>",{}]
```

每侧从以下四种子布局中选择一个：

| 子布局 | 固定角色 | 对齐与弹性 |
|---|---|---|
| `Sub-118-A` 核心居中 | 无标题、一个核心内容、无动作 | 单一 Data Display 双轴居中 |
| `Sub-118-B` 标题单内容 | 局部标题 + 一个内容、无动作 | 内容承接剩余高度，左对齐并贴底 |
| `Sub-118-C` 标题双内容 | 局部标题 + 上核心 + 下明细、无动作 | 上槽左上并吸收剩余高度；下槽自然高度贴底 |
| `Sub-118-D` 标题内容单按钮 | 局部标题 + 一个内容组 + 一个 `PillButton` | 内容承接剩余高度，动作以固定间距沉底 |

### `W-content-side-slots`（完整内容区 + 固定双槽）

- 适用：一个不使用 `InfoBlock` 的完整内容区，加两个可独立辨认的紧凑信息或动作槽。
- 外层：内容区与槽列等权，间距 `12vp`；槽列上下槽等权，间距 `12vp`。可按 `orientation` 整体镜像。
- 固定槽：只允许“动作 + 动作”“信息 + 信息”“信息 + 动作”。混合时 `InfoBlock` 在上、`CardButton` 在下。
- 限制：两个槽必须同时存在，不复制字段、不虚构模块、不生成空槽；固定槽内不嵌套 `PillButton`。
- 动作：完整内容区内的直属动作使用 `PillButton`；固定动作槽使用 `CardButton`，且整个槽为点击边界。

```genui
["root","Row",{"width":"matchParent","height":"matchParent","padding":12,"itemMargin":12,"alignItems":"center","justifyContent":"start"},["content","slots"]]
["content","Column",{"width":"matchParent","height":"matchParent","layoutWeight":1},["<Sub-140 内层 id>"]]
["slots","Column",{"width":"matchParent","height":"matchParent","itemMargin":12,"layoutWeight":1},["upper_slot","lower_slot"]]
["upper_slot","<InfoBlock 或 CardButton>",{"width":"matchParent"}]
["lower_slot","<InfoBlock 或 CardButton>",{"width":"matchParent"}]
```

完整内容区从以下七种子布局中选择一个：

| 子布局 | 固定角色 | 对齐与弹性 |
|---|---|---|
| `Sub-140-A` 核心居中 | 无标题、一个核心内容、无动作 | 单一 Data Display 双轴居中 |
| `Sub-140-B` 标题单内容 | 局部标题 + 一个内容、无动作 | 内容承接剩余高度，左对齐并贴底 |
| `Sub-140-C` 标题内容单按钮 | 局部标题 + 一个内容 + 一个 `PillButton` | 内容承接剩余高度，动作沉底 |
| `Sub-140-D` 标题双列内容可选按钮 | 局部标题 + 两个同级占比 + 可选 `PillButton` | 双列等权并居中；无动作时删除按钮和相邻间距 |
| `Sub-140-F` 标题主次内容单按钮 | 局部标题 + hero + support + `PillButton` | hero/support 为一个紧密连续组，动作沉底 |
| `Sub-140-G` 标题双内容 | 局部标题 + 上核心 + 下明细、无动作 | 上槽左上并吸收剩余高度；下槽自然高度贴底 |
| `Sub-140-H` 内容四宫格 | 无标题、四个同级占比、无动作 | 两行两列等权，每格双轴居中 |

### `W-four-slots`（四槽宫格）

- 适用：恰好四个同级、可独立表达的真实信息或动作模块。
- 外层：无公共标题；两行两列等权分配，横纵间距均为 `12vp`。
- 槽位：每格只放一个完整 `InfoBlock`、`CardButton` 或同槽位合法组件组合。存在 Action 的槽必须是完整点击边界。
- 排列：混用信息槽与动作槽时，同类组件放在同一列并按上到下排列；四槽全部同类时按业务阅读顺序填充。
- 限制：不使用空槽、占位、第五个模块、格内胶囊按钮或嵌套背板；不为凑满四格复制字段或虚构动作。

```genui
["root","Column",{"width":"matchParent","height":"matchParent","padding":12,"itemMargin":12},["row_one","row_two"]]
["row_one","Row",{"width":"matchParent","itemMargin":12,"layoutWeight":1},["slot_a","slot_b"]]
["row_two","Row",{"width":"matchParent","itemMargin":12,"layoutWeight":1},["slot_c","slot_d"]]
["slot_a","<同级真实信息或动作组件>",{"width":"matchParent","height":"matchParent","layoutWeight":1}]
["slot_b","<同级真实信息或动作组件>",{"width":"matchParent","height":"matchParent","layoutWeight":1}]
["slot_c","<同级真实信息或动作组件>",{"width":"matchParent","height":"matchParent","layoutWeight":1}]
["slot_d","<同级真实信息或动作组件>",{"width":"matchParent","height":"matchParent","layoutWeight":1}]
```

### 最终检查

- 只使用一个正式一级布局，不跨骨架拼接区域。
- 标题作用域正确：`W-top-bottom` 可使用整卡标题；左右布局只在所属内容区内使用局部标题；`W-four-slots` 无标题槽。
- 每个 Action 保留原语义归属且只有一个点击容器；不把按钮当作独立业务对象。
- Sub-118/Sub-140 的居中、左上、左下、底部动作与固定间距已由对应外层容器显式表达。
- 容量不足时先删除 `shouldKeep`，再改选能承载全部 `mustKeep` 的布局；不依赖 `clip`、`maxLines` 或缩小 Recipe 隐藏溢出。
