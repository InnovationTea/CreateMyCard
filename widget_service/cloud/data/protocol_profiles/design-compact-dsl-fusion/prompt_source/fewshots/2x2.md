# 2x2 Few-shot

先判断信息关系和必须保留的事实、动作，再参考匹配案例；示例不授权额外字段、路径、素材或事件。
不能把多指标、状态加明细、列表或带动作请求缩减成单值卡片，也不能照抄示例的数据值、标题、颜色或 id。
数值、单位、标签与所属对象必须成组；动态值继续绑定，已有单位的字符串完整保留，不从中截取数字造进度。
高阶组件在语义、类型和容量匹配时优先使用；容纳不下必要信息时改用其它合法语义组件组合，不为组件用量删信息。
保留组件的内部视觉契约；同一个内容组可在预算内使用纵排、等宽短数值列、弹性留白和底部动作。
案例几何仅作参考，实际以本轮画布安全区、完整动态文本和组件展开后的尺寸复核。
用户显式要求的动作必须保留；候选中存在动作或素材本身不代表用户要求，不能照搬案例的隐式入口。
背景与融球服从本轮运行时门禁和主提示词配色；缺少准确素材就使用文字，不复制未声明图标。

区域直接使用 `matchParent` 与 `layoutWeight`，不照抄参考宽高；固定 padding、字号、图标、圆环、按钮高度和组内间距保持组件合同原值。标题与图标锚定所属区域，正文承接剩余空间，普通按钮锚定底部；不把新增空间拉大为文字间距。
