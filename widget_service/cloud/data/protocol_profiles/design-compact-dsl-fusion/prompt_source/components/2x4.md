# 宽卡组件限制（维护源）

> 维护说明不发给模型；仅 `prompt` 标记内正文参与构建。

## 边界与阅读顺序

宽卡高阶组件 → 通用组件的 2x4 适配 → 白色内容背板透明度。槽位仍以 layouts/2x4.md 为准。

## 2x4 高阶组件（维护导航，不发模型）

| 组件 | 语义合同 | Props | 当前案例 |
|---|---|---|---|
| `TextBlock` | `W-top-bottom` progress-detail 的两个同级详情背板 | `items`、`fontColor`、`backgroundColor` 必填；`items` 恰好 2 项，每项包含 `label`、`value` | - |
| `CardButton` | 固定槽中的一个真实动作 | `label`、`onClick`、`fontColor`、`backgroundColor` 必填；`icon`、`fillColor` 可选 | V08/V12/V18/V19/V20 |
| `ProgressCircleSingle` | `W-split-panels` 的环形主指标与右侧说明 | `value`、`total`、`icon`、`displayValue`、`label` 与配色必填；`secondaryLabel` 可选 | - |
| `TopTextBottomValue` | `W-top-bottom` metric-triple 三项等权指标 | `items`、`fontColor`、`dividerColor` 必填；每项包含 `label`、`value`、`unit` | - |
| `SummaryList` | `W-top-bottom` list-rows 的 2–3 条单行摘要 | `items`、`fontColor`、`backgroundColor` 必填 | - |

`TextBlock` 固定展开为两个 `134×48vp` 背板，不接受宽高、圆角、padding 或对齐 Props。
`CardButton` 固定展开为 `132×57vp` 可点击背板；右侧固定为 `24×24vp` 视觉位，有图标时渲染真实图标，
无图标时由确定性视觉配方渲染中性占位。`onClick` 必须逐字使用当前事件候选，模型不得伪造图标路径。

## 通用组件的 2x4 适配（维护导航，不发模型）

- `InfoBlock` 只用于 `W-content-side-slots` 与 `W-four-slots` 的 `132×57vp` 固定槽；完整父区不属于 `InfoBlock`。
- `ProgressLine2` 只使用 `W-top-bottom` 的 progress-detail 主内容区，进度值与可见读数必须来自同一业务关系。
- `EmphasizedData` 只表达一个主数值，不吸收右侧辅助槽或底部详情。
- 当前 2x4 Few-shot 没有稳定的 `TableText` 实例，本阶段不建立宽卡槽位。

## 2x4 高阶组件适配

通用选择条件、Props、绑定和 Compact DSL 示例见组件协议；本节只规定 2x4 的合法槽位与固定展开。
高阶组件均不带 children，也不传几何或排版 Props。

### `EmphasizedData`

#### 合法槽位

只进入 `W-content-side-slots` 的 `132×126vp` 完整内容区，用于唯一核心量化值；不吸收固定辅助槽或底部详情。

#### 固定展开

展开为宽 `132vp` 的数值行：主值 `30fp/700`，可选单位 `12fp/500`，间距 `2vp`，两者底部对齐。

#### 注意事项

完整内容区没有唯一核心值时不要强行使用，多个同级指标保持原布局表达。

### `InfoBlock`

#### 合法槽位

`variant:"slot"` 只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定槽。2x4 必须显式填写该 variant。

#### 固定展开

主信息固定 `14fp/700`，辅助信息固定 `12fp/500`，两行由固定文字列垂直居中；可带右侧 `24×24vp` 图标或整块 `onClick`。

#### 注意事项

`W-split-panels` 的 `132×126vp` 完整父区不属于 `InfoBlock`。图标不能挤压到主辅文字无法单行完整展示。

### `ProgressLine2`

#### 合法槽位

只进入 `W-top-bottom` 的 progress-detail 整宽主进度槽，并与同一预设中的 `TextBlock` 组成“主进度 + 双详情”。

#### 固定展开

整体 `276×50vp`：上方显示 `30fp/700` 读数与可选 `12fp/500` 单位，下方为 `276×8vp`
线性进度条；读数到进度条间距 `6vp`，底部留白 `4vp`。

#### 注意事项

可见读数与进度条必须来自同一真实进度关系，不能缺少可见数值或用格式化字符串驱动进度值。

### `TextBlock`

#### 合法槽位

只进入 `W-top-bottom` 的 progress-detail 下方详情槽，`items` 恰好两个并与上方 `ProgressLine2` 属于同一主题。

#### 固定展开

展开为一行两个 `134×48vp` 背板，中间间距 `8vp`；每个背板显示一行标签和一行值。

#### 注意事项

两个详情必须同级；不要把主进度、动作或无关业务放入 `items`。

### `CardButton`

#### 合法槽位

只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定动作槽，一个实例只承载一个真实动作。

#### 固定展开

左侧是 `14fp/700` 单行文案，右侧是 `24×24vp` 固定视觉位，间距 `8vp`；有图标时渲染真实图标，
无图标时渲染中性占位。

#### 注意事项

事件必须逐字使用当前候选；无图标时不得伪造资源路径。`TableText` 当前不用于 2x4。
`PillButton`、`CircleButton` 当前只用于 2x2；2x4 固定动作槽继续使用 `CardButton`，其它动作沿用合法基础组件组合。

### `ProgressCircleSingle`

#### 合法槽位

只进入 `W-split-panels` 的 ring-detail 预设，用于一个具有真实范围的环形主指标和右侧读数；必须有
语义匹配的环心图标，可选一条同对象状态说明。

#### 固定展开

整体无状态时 `276×44vp`，存在状态时 `276×46vp`：左侧 `44×44vp`、描边 `6vp` 的 Progress，
环心放 `20×20vp` 图标；右侧放 `14fp/700` 标签、可见读数及可选状态。存在状态时两条辅助文字使用
`10fp/400`。

#### 注意事项

不得用于温度、日期、时间、时长或无可靠总量的数据；环形 Progress 不能脱离可见读数。

### `TopTextBottomValue`

#### 合法槽位

只进入 `W-top-bottom` 的 metric-triple 预设，且必须恰好三个同级指标。

#### 固定展开

整体 `276×68vp`，三个 `90×68vp` 指标区由两个 `1×62vp` 分隔线分开；视觉固定为
`12fp/500` 标签、`24fp/700` 数值、`12fp/400` 单位三行。

#### 注意事项

存在唯一主指标或项目数不是三个时不用。组件名不改变上述固定视觉顺序。

### `SummaryList`

#### 合法槽位

只进入 `W-top-bottom` 的 list-rows 预设，承载 2–3 条同级短摘要。

#### 固定展开

每项是 `276×28vp` 单行背板，项目间距 `8vp`；两项总高 `64vp`，三项总高 `102vp`。

#### 注意事项

每项必须能单行完整显示；不嵌套标签、图标、按钮或动态模板。
