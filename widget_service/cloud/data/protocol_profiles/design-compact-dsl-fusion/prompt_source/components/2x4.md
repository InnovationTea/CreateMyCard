# 宽卡组件

<!-- prompt:selection -->
## 2x4 组件适配总表

| 组件 | 合法落点 / 容量差异 | 注意事项 |
|---|---|---|
| InfoBlock | 仅132×57vp固定信息槽 | 必填 variant:slot，不进入Region/Group |
| ProgressCircleSingle | 完整内容区，compact环44vp；带状态整体46vp | 图标20vp，不进入固定槽 |
| ProgressCircle | 双/四比例专用槽 | 由槽注入外框，不输出宽高 |
| EventCard | 完整内容区 | 不受小卡116vp最大宽限制 |
| ProgressLine2 | 连续内容区，至少50vp | 真实进度及完整读数 |
| TextBlock | 仅 W-top-bottom.details，按槽宽选择项数，至少48vp | 满宽276vp按280vp横向预算允许4项；窄槽位仍按实际宽度核算 |
| TopTextBottomValue | 仅 W-top-bottom.details，恰好3项，高68vp | 每项标签/数值/单位 |
| SummaryList | 仅 W-top-bottom 列表明细 | 2项64vp，3项102vp |
| PillButton | 完整内容区直属动作，宽116/132vp、高36vp | 不进入固定模块槽 |
| CardButton | 仅132×57vp固定动作槽 | 与相邻InfoBlock等高 |

其它共享组件容量不因卡片变宽自动降低。2x4 不使用 DataDisplay、CircleButton；图标无小卡数量上限，每个实例须有语义增益且满足预算，普通图标20vp。

## 2x4 组件细则

### InfoBlock 尺寸示例

固定槽使用 variant:slot；主信息、辅助信息各至多一个动态字段。图形仍遵守真实比例和素材规则。

```genui
["sleep","InfoBlock",{"variant":"slot","primaryText":{"path":"/data/healthSport/sleepScore"},"unit":"分","secondaryText":"{{ '状态 ' + ${/data/healthSport/sleepStatus} }}","visual":{"type":"icon","icon":"resources/base/media/moon_z_fill_1.svg"},"fillColor":"#991F4799","backgroundColor":"#99FFFFFF"}]
```

```genui
["battery","InfoBlock",{"variant":"slot","primaryText":{"path":"/data/phoneBattery/batterySOC"},"unit":"%","secondaryText":{"path":"/data/phoneBattery/chargingStatusDesc"},"visual":{"type":"progressCircle","icon":"resources/base/media/battery_leaf_fill.svg"},"fillColor":"#991F4799","backgroundColor":"#99FFFFFF"}]
```

## 专属组件

### 1. `ProgressLine2`

#### 选择条件

用于当前数值相对明确总量的真实线性进度，并同时展示可见读数。没有真实分母、总量或比例关系时不使用；
仅因为内容含 `%` 不自动成为进度。

#### 组件属性

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `value` | number / string / PathBinding | 静态 / PathBinding；不接受 Expression | 必填；数值、纯数值字符串或完整百分比字符串；百分比字符串按 `total` 等比换算 |
| `total` | number | 仅静态 | 必填；正数 |
| `displayValue` | 显示值 | 静态 / Expression / PathBinding | 必填；与 `value/total` 表达同一事实 |
| `unit` | string | 静态 / Expression / string PathBinding | 可选；读数未包含单位时填写 |
| `color`、`backgroundColor` | `#AARRGGBB` | 仅静态 | 必填 |

#### 槽位与容量

进入合法连续内容区，至少50vp。

#### 示例

```genui
["score","ProgressLine2",{"value":{"path":"/data/healthSport/sleepScore"},"total":100,"displayValue":{"path":"/data/healthSport/sleepScore"},"unit":"分","color":"#FF563D99","backgroundColor":"#33563D99"}]
```

#### 注意事项

`value`、`total` 和 `displayValue` 必须属于同一进度关系；`value` 只接受纯数值或完整百分比字符串，
不能从包含标签、单位说明或其它正文的字符串中截取数字。

### 2. `SummaryList`

#### 选择条件

用于 2–3 条同级、可单行完整显示的短摘要。长正文、标签—值或存在主次关系的内容不使用。

#### 组件属性

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `items` | 显示值数组 | 数组结构仅静态；每项可静态 / Expression / PathBinding | 必填；2–3 条显示值 |

#### 槽位与容量

仅进入 W-top-bottom 列表明细槽；组件撑满明细槽并将列表贴底，沿用卡片12vp安全边距。
每项28vp、间距8vp；两项至少64vp、三项至少102vp。每项背板与TextBlock一致，由Runtime固定
使用当前主题的内容背板色；文字颜色也由Runtime注入，模型不输出颜色属性。

#### 示例

动态绑定的单组件示例：

```genui
["list","SummaryList",{"items":[{"path":"/data/calendar/events/0/title"},{"path":"/data/calendar/events/1/title"},{"path":"/data/calendar/events/2/title"}]}]
```

静态行程摘要只有在 Plan 已接受这 2–3 条同级短事实，或有界降级已明确授权省略
其它非 Action 事实时才可使用。完整布局示例：

```genui
["root","Layout",{"layout":"W-top-bottom","variant":"continuous"},["title","details"]]
["title","SingleLineTitle",{"title":"杭州2天1晚秋日漫游","fontSize":12}]
["details","SummaryList",{"items":["Day1 13:30-16:30 浙江省博物馆新馆","Day1 17:00-19:00 清河坊历史文化街区","Day1 19:00 赵府私厨晚餐"]}]
```

#### 注意事项

条目不嵌套标签、图标或按钮；超出三条时按信息优先级取舍或改选布局，不使用动态数组模板。
用户明确要求完整清单且 Plan 仍保留超过三条必需事实时，该组件容量不成立；
不得只选其中三条便声称已覆盖完整 Plan。

### `TopTextBottomValue`

只进入 `W-top-bottom` 的 details，且必须恰好三个同级指标。整体固定高 `68vp`，转换器生成三个等宽指标区
和两个分隔线；每项按标签、数值、单位顺序展示。标签与单位为静态短文本，动态绑定只放在同项 `value`。

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `items` | Array | 数组结构仅静态 | 必填；恰好三项 |
| `items[].label` | string | 仅静态 | 必填；非空短标签 |
| `items[].value` | 显示值 | 静态 / Expression / PathBinding | 必填；真实可见值 |
| `items[].unit` | string | 仅静态 | 必填；短单位；值已含单位时不得重复 |
| `dividerColor` | `#AARRGGBB` | 仅静态 | 必填 |

```genui
["metrics","TopTextBottomValue",{"items":[{"label":"最高","value":{"path":"/data/weather/high"},"unit":"℃"},{"label":"最低","value":{"path":"/data/weather/low"},"unit":"℃"},{"label":"湿度","value":{"path":"/data/weather/humidity"},"unit":"%"}],"dividerColor":"#331F4799"}]
```

### `TextBlock`

只允许进入 `W-top-bottom` 的 details；选择其它 2x4 骨架时禁止输出 `TextBlock`。若当前信息确实需要
`TextBlock`，应把整卡改选为 `W-top-bottom`，不得将它塞入 `W-content-side-slots` 的完整内容区或固定槽，
也不得塞入 `W-split-panels`、`W-four-slots`。它并列展示 2–4 个同级标签—值，项目沿横向等权撑满可用宽度，只保留固定
`8vp` 项间距，不使用 `spaceBetween` 生成额外空白。组件高度撑满 details 父槽位且最小为 `48vp`，高度上限
由父布局预算决定。容量选型仍以每项 `64vp` 作为参考下限；实际 A2UI 展开不写死该最小宽，所有 item 通过
`layoutWeight:1`、`flexShrink:1` 等权分配扣除固定间距后的可用宽度。选型必须满足
`项数×单项最小宽 + (项数−1)×间距 ≤ 横向校验预算`，具体参数以本轮容量合同为准。
当前276vp满宽details的四项组合按280vp预算判定，不因4vp差额拒绝；实际渲染时每项获得63vp，
不会越过卡片右侧安全边距。
窄分区仍按实际宽度检查，超过允许预算时改选合法组件或布局承载全部事实。
输入应保证标签和值能在真实宽度中单行完整显示，运行时仅以省略号兜底；不为保持外观删除第三、第四项，
也不把主进度、动作或无关对象放入 `items`。内部标签固定为
`12fp/700` 并在 `18vp` 行盒内垂直居中，值固定为 `10fp/500` 并在 `16vp` 行盒内垂直居中，均左对齐。

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `items` | Array | 数组结构仅静态 | 必填；2–4 项 |
| `items[].label` | 显示值 | 静态 / Expression / PathBinding | 必填；非空短标签 |
| `items[].value` | 显示值 | 静态 / Expression / PathBinding | 必填；真实可见值 |

每项背板由 Recipe 固定使用当前 2x4 内容背板色，模型不输出 `backgroundColor`。

```genui
["details","TextBlock",{"items":[{"label":"湿度","value":{"path":"/data/greenhouse/humidityText"}},{"label":"光照","value":{"path":"/data/greenhouse/lightStatus"}},{"label":"土壤","value":{"path":"/data/greenhouse/soilStatus"}}]}]
```

需要纵向标签—值时使用共享 `TableText`，不要强行把长值塞入横向等分背板。

### `CardButton`

只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定动作槽，一个实例承载一个真实动作。
左侧缺省单行文案，右侧为固定图标位；有准确素材时必须使用 Plan 已分配给该动作的候选素材。没有素材时仍保留文字按钮，转换器展示固定回退图标 `resources/base/media/ic_fallback_light.svg`。事件必须逐字复用当前候选。

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `label` | string | 仅静态 | 必填；完整动作与目标文案 |
| `labelLines` | 1 / 2 | 仅静态 | 可选，缺省1；2以原14字号分两行，占高40 |
| `icon` | string | 仅静态 | 可选；存在 Plan 分配时逐字使用当前素材候选路径；没有分配时省略整个 Prop |
| `fillColor` | — | — | 不输出；单色 SVG 由运行时按按钮前景色自动染色，位图保留原色 |
| `onClick` | EventHandler[] | 事件参数按事件 schema | 必填；恰好一个当前事件候选中的 handler |

背板由 Recipe 固定使用当前 2x4 内容背板色，模型不输出 `backgroundColor`。带图标时，参考动作槽中扣除左右padding、
图标和间距后，文案可用宽度为 `76vp`；无图标时不扣图标宽度和间距，文字承接完整剩余宽度。区域变宽时文字继续承接新增宽度。
缺省单行超出文字区时由 Recipe 在尾部显示省略号并产生 warning，不因此拒绝整张卡；原始完整 label
和事件保持不变。需要完整展示动作与目标时使用 `labelLines:2`，40vp文字加上下padding14vp可放入57vp参考槽；
字号、槽位高度、图标、padding均不改变。两个字以内的短值不能作为任意长标签的容量依据。
两行仍不能容纳必要目标时，改选其它合法动作组件及父布局，保留动作与完整目标；不创建低阶可点击容器，不改内部规格，也不重复入口。
如果 Plan 没有给该动作分配图标，仍可生成 `CardButton`，原始 DSL 必须省略 `icon`；转换器会展示固定回退图标 `resources/base/media/ic_fallback_light.svg`，不生成额外圆形、分隔线或其它占位。

```genui
["settings","CardButton",{"label":"蓝牙设置","icon":"resources/base/media/bluetooth_fill.svg","onClick":[{"call":"clickToDeeplink","args":{"intentName":"Settings","bundleName":"com.huawei.hmos.settings","abilityName":"com.huawei.hmos.settings.MainAbility","uri":"bluetooth_entry"}}]}]
```
