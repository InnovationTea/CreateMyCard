# 宽卡组件限制（维护源）

> 维护说明不发给模型；仅 `prompt` 标记内正文参与构建。

## 边界与阅读顺序

宽卡高阶组件 → 通用组件的 2x4 适配 → 白色内容背板透明度。槽位仍以 layouts/2x4.md 为准。

## 2x4 高阶组件（维护导航，不发模型）

| 组件 | 语义合同 | Props | 当前案例 |
|---|---|---|---|
| `TextBlock` | `W-top-bottom` progress-detail 的两个同级详情背板 | `items`、`fontColor`、`backgroundColor` 必填；`items` 恰好 2 项，每项包含 `label`、`value` | - |
| `CardButton` | 固定槽中的一个真实动作 | `label`、`onClick`、`fontColor`、`backgroundColor` 必填；`icon`、`fillColor` 可选 | V08/V12/V18/V19/V20 |
| `ProgressCircleSingle` | `W-top-bottom` 的 ring-summary 紧凑环形读数组 | `value`、`total`、`icon`、`displayValue`、`label` 与配色必填；`secondaryLabel` 可选 | V02 |
| `TopTextBottomValue` | `W-top-bottom` metric-triple 三项等权指标 | `items`、`fontColor`、`dividerColor` 必填；每项包含 `label`、`value`、`unit` | - |
| `SummaryList` | `W-top-bottom` list-rows 的 2–3 条单行摘要 | `items`、`fontColor`、`backgroundColor` 必填 | - |

`TextBlock` 固定展开为两个 `134×48vp` 背板，不接受宽高、圆角、padding 或对齐 Props。
`CardButton` 固定展开为 `132×57vp` 可点击背板；右侧固定为 `20×20vp` 视觉位，有图标时渲染真实图标，
无图标时由确定性视觉配方渲染中性占位。`onClick` 必须逐字使用当前事件候选，模型不得伪造图标路径。

## 通用组件的 2x4 适配（维护导航，不发模型）

- `InfoBlock` 只用于 `W-content-side-slots` 与 `W-four-slots` 的 `132×57vp` 固定槽；完整父区不属于 `InfoBlock`。
- `ProgressLine2` 只使用 `W-top-bottom` 的 progress-detail 主内容区，进度值与可见读数必须来自同一业务关系。
- `EmphasizedData` 只表达一个主数值，不吸收右侧辅助槽或底部详情。
- 当前 2x4 Few-shot 没有稳定的 `TableText` 实例，本阶段不建立宽卡槽位。

## 2x4 组件选型

| 组件 | 内容、绑定与容量 | 排除条件 |
|---|---|---|
| InfoBlock | slot 变体的 primaryText/secondaryText，两行完整短信息 | 不承载事件，不将三项长事实挤入两行；完整父区不是信息槽 |
| EmphasizedData | 一个短核心量化值与可选 unit，独立说明在所属内容区 | 无唯一焦点、日期时间或长单位不套大字组件 |
| ProgressLine2 | value/total 真实比例＋同指标 displayValue，可选 unit；主进度组约 50vp 高 | 无真实数值/范围时不用；不以进度条代替可见读数 |
| TextBlock | items 恰好两项 label/value，两个同级详情背板约 48vp 高 | 不省略第三项凑双详情；不承载动作或跨对象混合读数 |
| ProgressCircleSingle | value/total 真实比例＋准确 icon＋label/displayValue/可选 secondaryLabel | 单个紧凑横向环形读数组，不是左右两大父区；缺真实数值、范围或准确图标时不用 |
| TopTextBottomValue | items 恰好三个等权 label/value/unit，三列约 68vp 高 | 不为凑三列补造或删除指标，不用于有明显主次的信息组 |
| SummaryList | items 为 2–3 条同级短摘要；每条单行，2 项高 64vp、3 项高 102vp | 多字段长记录、图标、按钮或必须换行的条目不能塞进单行背板 |
| CardButton | label＋真实 onClick；固定动作槽，可选准确图标 | 长动作名放不下时保持完整目标，改用合法基础动作；不改内部字体或删必要目标 |

宽卡不推荐 TableText、DataDisplay、EventCard、PillButton、CircleButton。
ProgressLine2、TextBlock、ProgressCircleSingle、TopTextBottomValue、SummaryList 当前只进入无动作的
W-top-bottom；本轮有必要动作时不推荐这些组件，不因它们内部没有 onClick 就把动作另加到整卡。
候选事件存在不等于本轮有必要动作；以真实需求和 Plan 的 actionId 为准。
组件在合法内容槽内组合；Plan 不输出几何，DSL 再核算组件、标题、说明和动作的总预算。

## 2x4 高阶组件适配

通用选择条件、Props、绑定和 Compact DSL 示例见组件协议；本节只规定 2x4 的合法槽位与固定展开。
高阶组件均不带 children；仅可使用通用合同允许的根节点外部布局 Props，不覆盖内部排版。

### `EmphasizedData`

#### 合法槽位

用于合法布局内预算成立的核心内容槽，表达唯一核心量化值；不吸收固定辅助槽、底部详情或动作。

#### 固定展开

展开为宽 `132vp` 的数值行：主值 `30fp/700`，可选单位 `12fp/500`，间距 `2vp`，两者底部对齐。

#### 注意事项

完整内容区没有唯一核心值时不要强行使用，多个同级指标保持原布局表达。

### `InfoBlock`

#### 合法槽位

`variant:"slot"` 只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定槽。2x4 必须显式填写该 variant。

#### 固定展开

主信息固定 `14fp/700`，辅助信息固定 `12fp/500`，两行由固定文字列垂直居中；可带右侧 `20×20vp` 图标，外层和内部组件均不支持事件。

#### 注意事项

`W-split-panels` 的 `132×126vp` 完整父区不属于 `InfoBlock`。图标不能挤压到主辅文字无法单行完整展示。
无图标文字宽116vp，有图标只有88vp；每行只放完整短值或一组能完整容纳的标签和值。
“电量+状态+连接类型”等长摘要拆成独立行或改用完整内容区；已有主区的睡眠时长等同对象事实留在主区，
不要塞进另一个对象的手机辅助槽，从而把手机状态裁掉。

### `ProgressLine2`

#### 合法槽位

用于 `W-top-bottom` 的整宽主进度槽；存在恰好两项同主题详情时可与 TextBlock 组成 progress-detail。
没有双详情时不补造 items，保留真实说明并选择预算成立的连续内容组织。

#### 固定展开

整体 `276×50vp`：上方显示 `30fp/700` 读数与可选 `12fp/500` 单位，下方为 `276×8vp`
线性进度条；读数到进度条间距 `6vp`，底部留白 `4vp`。

#### 注意事项

可见读数与进度条必须来自同一真实进度关系，不能缺少可见数值或用格式化字符串驱动进度值。

### `TextBlock`

#### 合法槽位

用于 `W-top-bottom` 下方详情槽，items 恰好两个。可与同主题 ProgressLine2 组成 progress-detail，
也可承载普通核心信息的两项同级详情；不能因采用 TextBlock 就强加进度图。

#### 固定展开

展开为一行两个 `134×48vp` 背板，中间间距 `8vp`；每个背板显示一行标签和一行值。

#### 注意事项

两个详情必须同级；不要把主进度、动作或无关业务放入 `items`。

### `CardButton`

#### 合法槽位

只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定动作槽，一个实例只承载一个真实动作。

#### 固定展开

左侧是 `14fp/700` 单行文案，右侧是 `20×20vp` 固定视觉位，间距 `8vp`；有图标时渲染真实图标，
无图标时渲染中性占位。

132vp槽的可用文案宽度只有76vp，无图标时也一样。对象已有可见上下文时用“查看天气”等短命令；
仍放不下则回退合法基础文字动作，不缩略真实目标或丢动作。
14fp中文标签通常采用2至4字，例如“开启省电”“锻炼记录”“收藏歌单”“拨打家人”；这是等义短名，
不改变事件目标。不要照搬普通宽按钮的6至8字容量；五字及以上先检查真实宽度，不用省略号收尾。
必须逐字保留的长名称不能缩短时，改为同槽位可点击基础Row/Column，仅放完整文字、不保留可选图标；
整个背板仍是点击热区。不得传入padding/fontSize去改变CardButton内部视觉。

#### 注意事项

事件必须逐字使用当前候选；无图标时不得伪造资源路径。`TableText` 当前不用于 2x4。
`PillButton`、`CircleButton` 当前只用于 2x2；2x4 固定动作槽容量匹配时使用 `CardButton`，不匹配时及其它动作使用合法基础组件组合。

### `ProgressCircleSingle`

#### 合法槽位

用于 `W-top-bottom` 的紧凑环形读数组（ring-summary），可以独占无标题无动作的居中内容区。
组件内部已经包含环和右侧读数，不是 W-split-panels 的左右两大父区；必须有真实范围和语义匹配的
环心图标，可选一条同对象状态说明。它不替代原 ring-detail 的左右分区结构。

#### 固定展开

整体无状态时 `276×44vp`，存在状态时 `276×46vp`：左侧 `44×44vp`、描边 `6vp` 的 Progress，
环心放 `20×20vp` 图标；右侧放 `14fp/700` 标签、可见读数及可选状态。存在状态时两条辅助文字使用
`10fp/400`。

#### 注意事项

不得用于温度、日期、时间、时长或无可靠总量的数据；环形 Progress 不能脱离可见读数。

### `TopTextBottomValue`

#### 合法槽位

只进入 `W-top-bottom` 的 metric-triple 预设，且必须恰好三个同级指标。

#### 固定展开

整体 `276×68vp`，三个 `90×68vp` 指标区由两个 `1×62vp` 分隔线分开；视觉固定为
`12fp/500` 标签、`24fp/700` 数值、`12fp/400` 单位三行。

#### 注意事项

存在唯一主指标或项目数不是三个时不用。组件名不改变上述固定视觉顺序。

### `SummaryList`

#### 合法槽位

只进入 `W-top-bottom` 的 list-rows 预设，承载 2–3 条同级短摘要。

#### 固定展开

每项是 `276×28vp` 单行背板，项目间距 `8vp`；两项总高 `64vp`，三项总高 `102vp`。

#### 注意事项

每项必须能单行完整显示；不嵌套标签、图标、按钮或动态模板。
