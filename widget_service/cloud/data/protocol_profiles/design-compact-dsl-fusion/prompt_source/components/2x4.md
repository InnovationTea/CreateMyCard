# 宽卡组件限制（维护源）

> 维护说明不发给模型；仅 `prompt` 标记内正文参与构建。

## 边界与阅读顺序

本文件先规定共享组件在 2x4 中的尺寸适配，再定义 2x4 专属组件。组件语义、共享 Props、绑定和
Compact DSL 示例以 `common.md` 为准；一级几何与 Sub-118/Sub-140 结构以 `layouts/2x4.md` 为准。

## 2x4 专属组件总表（维护导航，不发模型）

| 类型 | 名称 | 内容结构 | 适用场景 | 容量与约束 |
|---|---|---|---|---|
| 整宽明细 | `TopTextBottomValue` | 三组标签—数值—单位 | `W-top-bottom` 的三项数值明细 | 恰好三组；只进入 details |
| 整宽明细 | `TextBlock` | 2–4 组并列标签—值 | `W-top-bottom` 的同级属性明细 | 2–4 项；只进入 details |
| 摘要列表 | `SummaryList` | 2–3 条单行短摘要 | `W-top-bottom` 的短列表 | 每项必须单行完整显示 |
| 固定操作 | `CardButton` | 文案 + 可选图标 | `132×57vp` 固定动作槽 | 一个真实动作；只进入固定槽 |

## 共享组件的 2x4 适配（维护导航，不发模型）

- `CardHeader` 可进入 `W-top-bottom` 卡级标题槽，或其它布局的具体内容分区标题槽。
- `InfoBlock` 只进入 `W-content-side-slots` 与 `W-four-slots` 的 `132×57vp` 固定信息槽。
- `ProgressLine2`、`ProgressCircleSingle`、`TableText`、`EventCard` 可进入预算成立的完整内容区；它们不是固定槽组件。
- `ProgressCircleSingle` 使用 compact 规格；`EventCard` 在 2x4 不再受 `116vp` 最大宽度限制。
- `ProgressCircle` 进入完整内容区中的双占比或四占比槽，不进入固定信息槽。
- `PillButton` 进入完整内容区的直属动作位；`CardButton` 进入固定动作槽。

## 2x4 组件选型

先按 `common.md` 的语义合同保留可行组件，再依据完整内容区、整宽 details 或固定槽确定落点。共享组件
不会因为卡片是 2x4 就失效；完整匹配专用结构时优先使用对应组件，不因 Text 更容易排版而拆散组件。

| 组件 | 2x4 使用条件 | 排除条件 |
|---|---|---|
| `CardHeader` | `W-top-bottom` 的卡级标题，或其它布局中具体内容分区的稳定单行主题 | 数值、状态、日期时间和动作不用作标题 |
| `InfoBlock` | `132×57vp` 固定信息槽中的一组完整主辅短信息 | 不进入完整内容区，不承载动作或第三行 |
| `ProgressCircleSingle` | 单个对象的真实占比，在完整内容区显示 compact 环、标签、读数与可选状态 | 不进入固定槽；无真实范围或准确图标时不用 |
| `ProgressCircle` | 两个或四个同级真实占比，在完整内容区的等规格指标槽中逐项使用 | 单个占比优先 `ProgressCircleSingle`；普通绝对量不用 |
| `ProgressLine2` | 当前值相对明确总量的真实进度，完整内容区至少保留 `50vp` | 无真实数值/范围、读数与进度不属于同一指标时不用 |
| `TableText` | 完整内容区中的 2–3 项纵向标签—值；两行至少 `34vp`、三行至少 `52vp` | 不进入固定槽，不代替比较、事件或进度结构 |
| `EventCard` | 完整内容区中的单事件标题、时间和可选地点；所属动作另放内容区动作位 | 多事件、普通时间属性或容量不足时不用 |
| `EmphasizedData` | 完整内容区唯一需要突出的短量化值与可选单位 | 不吸收固定槽、底部 details、动作或同级对比组 |
| `TextBlock` | `W-top-bottom.details` 的 2–4 项同级标签—值背板 | 不承担主进度、动作或跨对象混合读数 |
| `TopTextBottomValue` | `W-top-bottom.details` 中恰好三个等权标签—数值—单位 | 有唯一主指标或项数不为三时不用 |
| `SummaryList` | `W-top-bottom.details` 中 2–3 条同级单行短摘要 | 长记录、图标、按钮或必须换行的项目不用 |
| `PillButton` | Sub-118/Sub-140 完整内容区中的直属文字动作 | 不进入固定模块槽，不与 `CardButton` 重复同一动作 |
| `CardButton` | `132×57vp` 固定动作槽中的一个真实动作 | 不进入完整内容区；完整标签放不下时改用合法可点击槽 |
| `Text` | 单段重点文字、正文、标签、状态、补充说明，或没有固定组件可完整承载的剩余内容 | 不用多个 Text 重造上述已完整匹配的组件结构 |

2x4 不使用 `DataDisplay`、`CircleButton`。必要动作不会自动排除内容组件：先为动作保留布局登记的操作位，
再在剩余完整内容区核算共享组件；只有总预算不成立时才改选组件或布局，不能删除动作来采用无动作结构。

## 2x4 组件适配

### 共享组件容量与可用区域

| 组件 | 合法区域与容量 |
|---|---|
| `CardHeader` | 固定高 `20vp`；`W-top-bottom` 可作为卡级标题，其它布局只能作为所属内容分区的第一个子组件 |
| `InfoBlock` | 只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定信息槽；必须写 `variant:"slot"` |
| `ProgressLine2` | 进入 `W-top-bottom` 主进度槽，或 Sub-118/Sub-140 中至少 `50vp` 高的完整内容区；读数与进度属于同一指标 |
| `ProgressCircleSingle` | 进入完整内容区，使用 compact 规格：环 `44×44vp`、描边 `6vp`、环心图标 `20×20vp`；有状态时整体高 `46vp` |
| `ProgressCircle` | 进入 Sub-118/Sub-140 的双占比槽或四占比槽；每个实例按所在槽位填写外框 `width/height` |
| `TableText` | 进入完整内容区；两行至少 `34vp`、三行至少 `52vp`，不进入 `132×57vp` 固定槽 |
| `EventCard` | 进入完整内容区；无地点高 `34vp`、有地点高 `50vp`，宽度跟随所在区；所属动作使用独立操作组件 |
| `EmphasizedData` | 进入完整内容区的唯一核心量化位置；不吸收固定槽或底部 details |
| `PillButton` | 只进入 Sub-118/Sub-140 完整内容区的直属动作位；宽 `116vp` 或 `132vp`、高 `36vp` |

共享组件与动作可以在同一个 Sub-118/Sub-140 中组合，但必须先扣除 `PillButton 36vp` 和布局间距。
组件展开高度超出剩余内容区时改选布局或内容组件，不缩小 Recipe、不裁掉必要事实。

### 2x4 专属组件：`TopTextBottomValue`

只进入 `W-top-bottom` 的 details，且必须恰好三个同级指标。整体固定高 `68vp`，转换器生成三个等宽指标区
和两个分隔线；每项按标签、数值、单位顺序展示。标签与单位为静态短文本，动态绑定只放在同项 `value`。

```genui
["metrics","TopTextBottomValue",{"items":[{"label":"最高","value":{"path":"/data/weather/high"},"unit":"℃"},{"label":"最低","value":{"path":"/data/weather/low"},"unit":"℃"},{"label":"湿度","value":{"path":"/data/weather/humidity"},"unit":"%"}],"fontColor":"#FF1F4799","dividerColor":"#331F4799"}]
```

### 2x4 专属组件：`TextBlock`

只进入 `W-top-bottom` 的 details，并列展示 2–4 个同级标签—值。整体固定高 `48vp`，项间距 `8vp`，
转换器按项目数等分宽度。每项标签和值都必须能在真实等分宽度中单行完整显示；不为保持外观删除第三、
第四项，也不把主进度、动作或无关对象放入 `items`。

```genui
["details","TextBlock",{"items":[{"label":"湿度","value":{"path":"/data/greenhouse/humidityText"}},{"label":"光照","value":{"path":"/data/greenhouse/lightStatus"}},{"label":"土壤","value":{"path":"/data/greenhouse/soilStatus"}}],"fontColor":"#FF1F4799","backgroundColor":"#99FFFFFF"}]
```

需要纵向标签—值时使用共享 `TableText`，不要强行把长值塞入横向等分背板。

### 2x4 专属组件：`SummaryList`

只进入 `W-top-bottom` 的 list-rows details，承载 2–3 条同级短摘要。每项固定 `276×28vp`，项目间距
`8vp`；两项总高 `64vp`，三项总高 `102vp`。条目只放完整单行显示值，不嵌套标签、图标或按钮。

### 2x4 专属组件：`CardButton`

只进入 `W-content-side-slots` 或 `W-four-slots` 的 `132×57vp` 固定动作槽，一个实例承载一个真实动作。
左侧是单行文案，右侧是固定 `20×20vp` 视觉位；有准确图标时使用候选素材，无图标时由 Recipe 渲染
中性占位。事件必须逐字复用当前候选。

文案实际可用宽度为 `76vp`，通常使用 2–4 个汉字的无歧义短命令。必要目标无法完整保留时，使用同槽位
合法可点击 Row/Column，只保留完整动作文字；不得改写 CardButton 内部字号、padding 或视觉位，也不得
与内容区 `PillButton` 重复同一动作。

```genui
["settings","CardButton",{"label":"蓝牙设置","fontColor":"#FF1F4799","backgroundColor":"#99FFFFFF","onClick":[{"call":"clickToDeeplink","args":{"intentName":"Settings","bundleName":"com.huawei.hmos.settings","abilityName":"com.huawei.hmos.settings.MainAbility","uri":"bluetooth_entry"}}]}]
```
