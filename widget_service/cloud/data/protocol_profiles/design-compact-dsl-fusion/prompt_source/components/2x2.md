# 小卡组件限制（维护源）

> 维护说明不发给模型；仅 `prompt` 标记内正文参与构建。

## 边界与阅读顺序

本文件只规定共享组件在 2x2 中的容量与可用内容槽，以及 2x2 专属 `CircleButton`。组件语义、Props、
绑定和 Compact DSL 示例以 `common.md` 为准；一级几何以 `layouts/2x2.md` 为准。

## 2x2 组件容量（维护导航，不发模型）

| 组件 | 2x2 适配 |
|---|---|
| `SingleLineTitle` | 两种尺寸共享；每个语义分区最多一个，固定高 `20vp` |
| `DataDisplay` | 只进入 `S-center`；最大 `126×114vp` |
| `InfoBlock` | 只进入 `S-dual-info` 的上、下固定槽；每槽 `134×63vp` |
| `ProgressCircleSingle` | 使用普通规格；主体至少需要 `52vp` 高，不进入 `S-content-dual-action` 的 `38vp` 内容槽 |
| `ProgressCircle` | 双占比进入 `S-title-dual-column-action`，四占比进入 `S-quad-content`；每个实例按槽位填写外框宽高 |
| `TableText` | 进入能完整容纳 2–3 行的连续内容槽；两行至少 `34vp`、三行至少 `52vp` |
| `EventCard` | 使用父内容槽完整宽度但最大不超过 `116vp`；一个实例承载 1–2 个事件 |
| `PillButton` | 只进入布局明确提供的底部操作槽；默认 `126×36vp` |
| `CircleButton` | 只进入 `S-title-anchor` 的右下 `40×40vp` 锚点槽 |

## 2x2 组件选型

先按 `common.md` 的语义合同选择组件，再用本表检查小卡容量；完整匹配专用结构时优先使用对应组件，
不要因为基础文字结构更容易排版就拆散组件。

| 组件 | 2x2 使用条件 | 排除条件 |
|---|---|---|
| `SingleLineTitle` | 布局存在标题槽，且有稳定业务、对象、事项或分组主题 | 同一分区已有 SingleLineTitle；数值、状态、日期时间和动作不用作标题；不用正文组件替代 |
| `DoubleLineTitle` | 标题区需同时表达对象名称和紧密相关的状态或地点 | 主体容量不足或两项并非同一对象时不用 |
| `Badge` | 标题旁存在同一集合的真实数量 | 状态、百分比、时长和普通核心值不用 |
| `EmphasisText` | 一个文本结论或状态是本分区核心，可带一条同对象补充 | 数值核心、事件、比较和进度不用 |
| `SecondaryBody` | 单段普通正文、metadata，或同区 1–4 个短补充字段 | 核心结论、稳定表格、事件、比较和进度不用 |
| `H_BarChart` | 2–3 个对象比较同一指标，连续内容高度足够 | 不同比例、不同量纲或普通列表不用 |
| `NumericRatioStack` | 恰好三个图标可区分的同级占比，容量闭合 | 无准确图标或项数不为三时不用 |
| `DataDisplay` | 无标题、无动作、只有一个可独立理解的量化焦点 | 还有第二指标、独立说明或动作时不用 |
| `InfoBlock` | 两个独立对象各使用一个主辅信息块 | 有必要动作、单对象密集信息或任一行放不下时不用 |
| `ProgressCircleSingle` | 单个对象的真实占比，且需要环右侧标签、读数或同对象状态 | `38vp` 双动作正文槽、无真实范围或无准确图标时不用 |
| `ProgressCircle` | 两个或四个同级真实占比，每个对象可由环心图标准确区分 | 单个占比优先 `ProgressCircleSingle`；普通绝对量不用 |
| `TableText` | 同一主题的 2–3 项标签—值，实际内容槽能容纳完整行高 | 不进入固定双信息块；不能为套表格删除字段或动作 |
| `EventCard` | 1–2 个具有标题和时间的事件；两项用同一实例，必要时 compact | 超过两项、普通时间属性或容量不足时不用 |
| `EmphasizedData` | 内容区唯一需要突出的短量化值与可选单位 | 时间段、长单位、同级对比组或无主次内容不用 |
| `PillButton` | 能容纳完整动作文字的底部直属操作 | 不新增动作，不与 `CircleButton` 重复同一动作 |
| `CircleButton` | `S-title-anchor` 右下纯图标动作，且存在准确图标 | 能容纳文字动作时优先 `PillButton` |

2x2 不使用 `ProgressLine2`、`TextBlock`、`CardButton`、`TopTextBottomValue`、`SummaryList`。
动作指 Plan 中必须保留的操作，不是事件候选数量。先保留必要信息与动作，再选择能同时满足语义和容量的
组件与布局；组件本身不支持事件时，动作放在布局登记的独立操作槽。

## 2x2 组件适配

### 共享组件容量与可用区域

| 组件 | 合法区域与容量 |
|---|---|
| `SingleLineTitle` | 每个语义分区最多一个、固定高 `20vp`；进入标题槽或具体分区首行 |
| `DoubleLineTitle` | 进入连续标题区；主标题 18vp + 间距 4vp + 次信息 18–36vp，必须完整计入高度 |
| `Badge` | 只与标题组成 Row；固定高 `16vp`，不单独占内容槽 |
| `EmphasisText` | 普通规格为主文本 24vp + 间距 2vp + 可选次文本 16vp |
| `SecondaryBody` | body 单行 `20vp`、双行 `40vp`；metadata 单行 `18vp`；supporting 两项一行 `20vp`，3–4 项分两行，每行 `18vp`、行间距 `2vp` |
| `H_BarChart` | 两项至少 `71vp`；三项至少 `98vp`，只进入连续内容区 |
| `NumericRatioStack` | column 三项高 `56vp`；row 需完整宽度并保证每项读数不截断 |
| `DataDisplay` | 只进入 `S-center`，作为 root 的唯一内容组件；最大 `126×114vp`，无动作 |
| `InfoBlock` | 只进入 `S-dual-info` 的两个 `134×63vp` 固定槽；2x2 的 `variant` 省略或写 `stacked` |
| `ProgressCircleSingle` | 使用普通规格：环为 `52×52vp`、描边 `6vp`、环心图标 `20×20vp`；右侧文字组保持完整，不进入 `38vp` 内容槽 |
| `ProgressCircle` | 双占比在 `S-title-dual-column-action` 中一列一个；四占比在 `S-quad-content` 中一格一个；模型按槽位填写组件 `width/height` |
| `TableText` | 两行至少 `34vp`、三行至少 `52vp`；可进入能满足该高度的连续内容槽，不进入 `S-dual-info` 固定槽 |
| `EventCard` | 进入连续内容槽，最大宽 `116vp`；单项无地点 `34vp`、有地点 `50vp`；两项 compact 共 `72vp` |
| `EmphasizedData` | 进入合法内容槽中的唯一核心量化位置，宽度跟随槽位；不进入 `S-dual-info` |
| `PillButton` | 进入布局登记的底部动作位，固定高 `36vp`、圆角 `30vp`，默认宽 `126vp` |

### 两个同级占比

两个同级占比使用两个 `ProgressCircle`，作为 `S-title-dual-column-action` 的两个直属指标；不得用正文组件、
普通容器或 `ProgressCircleSingle` 重造双占比组合。每个 `externalText` 同时驱动本环和环外读数。

### 2x2 专属组件：`CircleButton`

只显示图标、不显示文字，仅用于 `S-title-anchor` 的右下锚点操作。组件本体固定 `40×40vp`，
环心图标固定 `20×20vp`。

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `icon` | string | 仅静态 | 必填；逐字使用当前素材候选路径 |
| `accessibility` | object | 仅静态 | 必填；`label` 写完整动作名称，可选 `description` |
| `onClick` | EventHandler[] | 事件参数按事件 schema | 必填；恰好一个当前事件候选中的 handler |
| `actionSurface` | `#AARRGGBB` | 仅静态 | 必填；按钮背景色 |
| `actionInk` | `#AARRGGBB` | 仅静态 | 必填；单色图标颜色 |

- `icon` 和事件必须逐字使用当前候选。
- 不生成位置、圆角、宽高、padding 或字体覆盖；定位和尺寸由 Recipe 与布局负责。
- 只有底部 `PillButton` 无法与必要内容共同闭合时才使用；不得与 `PillButton` 表示同一动作。

