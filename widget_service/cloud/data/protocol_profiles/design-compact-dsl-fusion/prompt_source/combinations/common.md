# 组件组合

<!-- prompt:selection -->
## 组合选择

一个组件能完整表达的信息不额外拆成多个实例；需要独立主辅或并列关系时才组合。优先保留已经正确的对象、标签、绑定与动作归属，组件候选不等于实例数。只有当前尺寸登记的 Group 或父布局角色可承载组合。
<!-- /prompt:selection -->

# 十一、多组件关系

| 组合 | 成立条件与角色 | 排除条件 |
|---|---|---|
| 标题与数量 | 同一真实集合的标题＋Badge数量 | 不是状态、温度、百分比；不能从可见项数猜总数 |
| 核心与补充 | 同对象核心＋解释/限定/短明细 | 同级对象、左右设备或最高最低不能任意降为辅助 |
| 核心、补充与操作 | 核心＋短补充＋直属操作 | 缺角色、操作属于其它对象时不用 |
| 单内容与操作 | 一个完整内容＋直属操作 | 不为动作拆散内容或补造说明 |
| 同级指标 | 2–4项同尺度、可识别的并列值 | 不任取一项放大；每项标签和值保持一组 |
| 双/三/四占比 | 真实比例或明确有界进度，分别可识别 | 绝对量、缺范围/图标时不用；不编造total |
| 双信息块 | 两组同级且独立可理解的主辅短信息 | 有唯一主结论或每块放不下时不用 |
| 双操作 | 一个紧凑内容及两个共同服务该内容或整卡的必要动作 | 分别作用于不同对象时留在各自内容区 |

同级项使用相同尺度、字重和对齐。横排每列必须容纳完整标签、值和单位；任一项过长时整组改合法纵排，不只压缩其中一项。
核心与多个辅助事实不等于多个核心；紧密补充可用现有组件的次文字，独立辅助项合入一个合法多 item 实例。不同字号角色不互塞以省空间，不能为大字号挤掉明细或动作。
普通同级指标不补造比例图。真实进度与同主题详情可组合进度组件＋详情组件，项数不足不补项。组合不能扩大事件能力，信息块不变成按钮。
同一事实或操作只承担一个语义角色，不跨区重复，不为满足项数编造数据、标题、图标或操作。独立动作进入合法独立槽，不强行绑定相邻信息。
