## 11.6 2x4 组合落地

### 内容区组合

| 内容区 | 可承载的组合 | 落地要求 |
|---|---|---|
| Sub-118 核心居中 | 单一核心内容 | 一个无需局部标题即可理解的内容组件 |
| Sub-118 标题单内容 | 标题 + 单内容 | 标题后只有一个紧凑内容组 |
| Sub-118 标题双内容 | 核心与补充 | 标题、核心、短补充顺序固定，二者属于同一主题 |
| Sub-118 标题内容单按钮 | 单内容与操作 | 内容和操作属于同一对象，操作为最后一个内容区角色 |
| Sub-118 标题双列内容可选按钮 | 双占比 + 可选共同操作 | 两列使用相同尺度和规格；操作同时服务两项 |
| Sub-118 内容双按钮 | 双操作 | 一个紧凑内容和两个同级必要操作 |
| Sub-140 核心居中 | 单一核心内容 | 一个无需局部标题即可理解的内容组件 |
| Sub-140 标题单内容 | 标题 + 单内容 | 标题后只有一个完整内容组 |
| Sub-140 标题内容单按钮 | 单内容与操作 | 内容和一个直属操作；操作为最后一个角色 |
| Sub-140 标题主次内容单按钮 | 核心、补充与操作 | 核心、短补充和直属操作属于同一主题 |
| Sub-140 标题双内容 | 核心与补充 | 核心回答主要问题，补充解释或限定核心 |
| Sub-140 内容四宫格 | 四占比 | 四个同级真实占比；普通四模块仍可按 layout 使用，但不属于四占比组合 |
| Sub-140 内容双按钮 | 双操作 | 一个紧凑内容和两个同级必要操作 |

### 父布局与固定槽组合

| 父布局 | 合法组合 | 限制 |
|---|---|---|
| `W-top-bottom` | 单一主题的主体 + 明细 | 明细使用 TextBlock 或 TopTextBottomValue；不承载操作组合 |
| `W-split-panels` | 两个完整内容区，或同一主题的核心与属性详情 | 两侧分别选择合法 Sub-118；操作留在所属内容区，不统一移到卡级 |
| `W-content-side-slots` | 一个完整内容区 + 双信息块、双操作或信息与操作槽 | 固定双槽只允许 CardButton + CardButton、InfoBlock + InfoBlock、InfoBlock + CardButton；顺序不得颠倒 |
| `W-four-slots` | 四个固定信息或操作模块 | 每槽一个 InfoBlock 或 CardButton；四槽全部是真实模块，同类模块按布局规则排列 |

### 2x4 专属约束

- 标题与数量没有独立 Badge 组件时，将真实数量放入所属内容区的完整摘要，不使用 Text 仿造标题角标。
- 双占比只进入登记的双列比例内容区；三占比作为一个紧凑内容组进入单内容位；四占比只进入
  Sub-140 内容四宫格。普通状态或绝对量不能为了使用这些组合改成 Progress。
- 固定槽只承载紧凑主辅信息或操作，不承载完整业务内容。InfoBlock 与 CardButton 的 Props、事件和
  visual 继续服从 components，不因进入组合而获得额外能力。
- 两个独立业务各自有操作时，优先使用 `W-split-panels`，让每个操作留在所属 Sub-118 内容区；只有
  两个操作共同服务同一大内容区时，才使用固定双操作槽。
- 主焦点、同行数值和数值单位的排版执行 core；组合层不按天气、电池、健康等业务名称创建专属结构。
