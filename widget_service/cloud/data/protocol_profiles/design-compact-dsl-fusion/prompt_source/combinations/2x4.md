# 宽卡组合

<!-- prompt:mapping -->
## 2x4 Group

| variant | children | 固定关系 |
|---|---|---|
| hero-support | [核心, 补充] | 同对象紧密主辅纵排，2vp |
| label-value | [标签组件, 读数组件] | 同指标说明与值纵排，2vp，单位仍由组件处理 |
| peer-pair | [同级组件, 同级组件] | 两个同级短模块等宽居中，横向8vp |
| title-count | [SingleLineTitle, Badge] | 同一集合的范围/名称＋真实数量，横向4vp，作为一个标题角色 |

每组恰好两个真实组件，只填 variant 和 children，不加背景或事件。无真实数量字段不用 Badge；数量只表达一次，成员详情仍由内容组件承载。
Group 只组织同区信息，不把独立对象包装为一个内容，也不将两个独立内容和按钮隐藏成单内容。比例、事件与详情优先使用其专用组件，不拆低阶文字。
紧凑/宽版 Region 的可用变体、限定组件及动作槽只在布局表定义；组合不能把宽版独有结构带入紧凑版。固定信息槽与动作槽不能互换事件能力。
