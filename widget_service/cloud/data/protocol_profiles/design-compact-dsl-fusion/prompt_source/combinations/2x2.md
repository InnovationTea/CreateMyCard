**2x2 单数值 Hero 安全盒前置约束**：仅当普通 带标题布局 最终可见结构严格为“顶部标题＋中部唯一纯数字主值（可带真实单位）＋底部单动作”时启用。`content_area` 固定 `width:126`、`layoutWeight:1`、`justifyContent:"center"`、`alignItems:"center"`；其内放置独立的 `hero_box Column`，固定 `width:106`、`height:58`并双轴居中，`hero_box` 内只有一个 `value_row Row`，该 Row 固定 `width:106`、`justifyContent:"center"`、`alignItems:"bottom"`。数字和单位整组使用 `38/16fp -> 30/14fp -> 24/12fp -> 20/12fp` 的降档序列：先按 schema `sampleValue` 构造至少三位数字的压力值，再加 20% 宽度余量；宽度超过 106vp 或文字行高超过 58vp 就使用下一档，直至同时通过。不得用截断、省略单位、压缩容器或同时给 `content_area` 设置固定高度替代降档。中部一旦含有日期、时间、状态、说明、第二指标、Progress 或 Image，就不进入本结构，改按对应的普通密度、V08、并列指标或专用骨架处理。本规则不新增 few-shot，也不要从现有睡眠、环图或双指标示例拼装结构。

<!-- /prompt:hero-box -->

<!-- prompt:paired-status -->
**2x2 单业务成对状态生成前置约束**：带标题布局 状态亚型同时包含一个主状态、两个同级辅助状态和一个底部按钮时，内容区固定只有主状态行与一个辅助摘要行；两个辅助状态必须合并为一个 `12fp/400`、`maxLines:1` Text，用短文字标签区分并以 ` | ` 分隔，例如 `左耳 未充电 | 右耳 未充电`。禁止为两个辅助状态分别创建 Row、Column、固定窄宽度槽或 Image；L/R 等方向只用短文字标签表达，不使用左右图标。此规则不适用于 V01、V06、`S-content-dual-action`、`S-dual-info` 和 2x4。

<!-- /prompt:paired-status -->

<!-- prompt:dual-ring-columns -->
**2x2 双列环形指标约束**：`S-title-dual-column-action` 的内容行固定为两个 `59vp` 列和 `8vp` 间距。每列必须且只能包含一个环形指标模块：外层 Column 在列内双轴居中，`Progress type:"ring"` 与该指标自己的可见值和标签共同表达一个可靠比例；两列使用相同环径、`strokeWidth`、字号、字重和垂直基线。不得替换为普通文字列、跨列模块或竖向 Divider。没有可靠 `current/total` 比例、任一值或标签无法完整显示时，改用纵向标签—值行及其它正式布局。

<!-- /prompt:dual-ring-columns -->

<!-- prompt:pressure-width -->
为降低小画布估算误差，`2x2` 对以下常见格式化值使用更保守的默认槽位；若按字段语义推导出的压力字符串更长，以更长结果为准：

- 数值和单位拆分后，`38fp` 纯数字与 12-16fp 单位组成的主值组至少分配 `104vp`，允许负号、三位数或更长单位时至少 `128vp`；默认独占一行。
- 数值和单位拆分后，`32fp` 纯数字与 12-16fp 单位组成的主值组至少分配 `88vp`，允许负号或三位数时至少 `104vp`；未拆分字符串仅按格式化主读数例外允许 20/24fp。
- `12fp` 的整数百分比至少 `40vp`；带小数的百分比至少 `56vp`。
- `12fp` 的 `HH:mm-HH:mm` 时间范围至少 `100vp`。
- “静态标签 + 动态时长/日期/金额/时间范围”默认占整行。两个格式化动态值只有在各自压力宽度、固定间距和 `4vp` 余量全部成立时才能并排，否则改为纵向两行或删除次要值。

<!-- /prompt:pressure-width -->

<!-- prompt:countdown -->
**2x2 倒计时布局约束**：有目标名称且无动作时使用 `S-title-content`，主值组左对齐并贴内容区底端；有一个动作时使用 `S-title-content-action` 或 `S-title-primary-secondary-action`，正文从左上开始且动作沉底；无标题且数值自身可理解时才使用 `S-center`。禁止把倒计时改造成居中标题、三锚点或其它未登记布局。

<!-- /prompt:countdown -->
