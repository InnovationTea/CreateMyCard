## 11.5 2x2 组合落地

| 正式骨架 | 可承载的组合 | 落地要求 |
|---|---|---|
| `S-center` | 单一核心内容 | 只承载一个无需标题即可理解的 `DataDisplay`，不附加补充或操作 |
| `S-title-content` | 标题 + 单内容 | 内容是一个完整语义组；有独立补充时改用标题双内容 |
| `S-title-dual-content` | 核心与补充 | 标题后依次输出核心与短补充；两个内容属于同一主题 |
| `S-quad-content` | 四占比 | 四格分别表达一个可识别的真实占比；普通四模块仍可按 layout 使用，但不属于四占比组合 |
| `S-title-content-action` | 单内容与操作 | 标题、内容、一个直属操作；操作沉底且不能省略真实内容 |
| `S-title-primary-secondary-action` | 核心、补充与操作 | 核心和补充自然撑高，操作属于同一主题；任一角色缺失时换骨架 |
| `S-title-dual-column-action` | 双占比 + 可选共同操作 | 两列各表达一个可靠比例，保持同规格；操作必须同时服务两项 |
| `S-title-anchor` | 核心、补充与独立图标操作 | 与文字动作布局同级；存在精确图标和真实事件、用户未要求动作文字且有左下支撑信息时可首选；信息密集时优先 |
| `S-content-dual-action` | 双操作 | 一个紧凑内容后跟两个必要操作；两个操作共同服务该内容或整卡 |
| `S-dual-info` | 双信息块 | 两个对象各使用一个完整 InfoBlock；不增加总标题、第三块或独立按钮 |

### 2x2 专属约束

- 单个大数值只有在它是唯一核心焦点时才能使用 Hero；同级双指标、三状态和四占比不得从中任取一个
  放大。Hero 的字号与压力宽度按 components 执行，内容区预算按对应 layout 执行。
- 两个同级普通指标不具备可靠比例时，不生成双环；改用两条对齐的“标签—值”信息。恰好三个同级
  状态使用纵向短行，不拆成三个大号焦点。
- `S-title-dual-column-action` 的两列必须都是环形比例模块，不能一列环图、一列普通文字，也不能加入
  额外分隔线。
- `S-dual-info` 的每个 InfoBlock 只表达所属对象的主信息和辅助信息，外层和内部组件均不支持事件；
  存在必须保留的显式动作时改选可承载动作的布局。
- 单个显式动作同时具备准确 SVG、主内容和左下支撑信息时，先比较 `S-title-anchor` 与文字动作布局；
  至少三项必要信息会与整宽按钮竞争正文空间时，`S-title-anchor` 排在文字动作布局之前。不得为了保留
  `PillButton` 把多个独立事实拼进一个 `SecondaryBody`、降低字号、取消信息间距或裁切文本。
- 倒计时、成对设备状态和融球只是业务或视觉场景，不是新的组件组合。它们先命中本表中的正式组合，
  再分别执行 layouts、components、core 的专属规则。
