## 边界与阅读顺序

## 小卡容量总表（维护导航，不发模型）

| 密度 / 信息关系 | 取舍入口 | 注意事项 |
|---|---|---|
| 稀疏单焦点 | density、density-gate | 仍按所选正式布局对齐，不增加弱字段填白 |
| 数字主焦点 + 支撑 | density-gate | 保留大数字时只有一条辅助；两条独立事实可先降低主读数字号 |
| 文字主焦点 | density-gate | 一条突出信息与最多两条辅助；短状态例外仍遵守 core |
| 同级指标 | density-gate、combinations/common | 两项可对称，三项优先标签值纵排 |
| 同日天气日期 | weather-date | date/weekday 不重复，标题已说明日期则去重 |
| 双业务 / 双动作 | 转至 layouts/2x2 | `S-dual-info`/`S-content-dual-action` 有独立预算，不能套普通密度 |

- **2x2 分行约束**：` | ` 只用于同层级、强相关、合并后仍完整通过单行压力预算且纵向确实受限的短信息。卡内仍有至少一行可用高度时，两个可独立理解的事实必须拆成两行；同一个 Text 引用两个及以上独立展示路径时，除固定小背板或明确受限的摘要槽外，优先判定为错误结构并改为两个 Text。不得为了维持 `maxLines:1` 把长句、标签和值全部横向挤在一行。一个事实本身需要换行时，只能按自然语义边界使用 `maxLines:2` 并显式预留两行高度，不能从数字、单位或固定词组中间断开。
