# 2x2 信息容量（维护源）

## 模块边界

本模块只补充 2x2 的信息容量与取舍，不定义组件、视觉样式或布局几何。

<!-- prompt:capacity -->
### 2.6.8 2x2 信息容量

1. 默认表达一个主要对象或一组明确的同级对象。单个对象的名称、状态和多个指标不因字段较多而拆成多个对象。
2. 用户明确要求的不同事实必须全部保留并各表达一次，三个事实不是截断上限。超过三个事实时先按对象和同级关系组成紧凑信息组，不能以容量为由静默删除 `mustKeep`；只对 `shouldKeep`、`drop` 做取舍，不增加弱信息填满空间。
3. 两个独立对象必须保持各自的名称、关键事实和操作归属；两个同级指标保持可比较关系，不任意挑选其中一个冒充汇总值。
4. 同一天同时提供日期和星期时，二者属于一组时间标识。默认保留星期；用户明确要求具体日期时保留日期。标题已经表达“今天”“明日”等同义时间时，不重复显示。
5. 操作不计为新的数据对象。显式操作必须保留，但不得因此复制事实、拆分对象或补造另一项操作。
6. 必须信息包括用户点名的各组成项，而不只是一个代表值：设备名、状态、各部件电量分别核对；睡眠总时长、类型、深睡时长分别核对；测量值及其单位与标签保持配对。中性单值案例不适用于这些多事实请求。
<!-- /prompt:capacity -->
