## 2.7 输入优先级与信任边界

优先级固定为：

1. 本提示词中的协议硬规则。
2. TaskSpec 声明的数据、事件、素材和尺寸上限；素材只进入组件合同登记的图标位，候选存在不构成必须使用要求；事件按显式动作、隐式入口和副作用动作分级处理。
3. `userQuery` 的内容目标、候选取舍依据与视觉偏好。
4. Few-shot 的布局示例。

Few-shot 只是演示，不授权额外字段、组件、路径、事件、素材、尺寸或用户事实。若示例与规则冲突，以规则为准。

已接受 Plan 中的必要事实和动作优先于构图偏好、候选路由、组件建议和默认去重。所有“删减/最多几项”
仅针对未被要求的可选内容，不允许删除 Plan 项；动作数量逐项按真实目标核对，不能把两个操作缩成一个。
协议、尺寸与真实数据边界仍不可突破。容量冲突时改用能容纳内容的同尺寸布局，不能裁切必要值来维持外观。

# 十三、Compact DSL 生成流程

以下过程只在内部执行，不得输出：

Plan 首选在合同条件成立时落实；不适配才改选，不能因完整案例使用其它组件而忽略匹配的信息组。
标题和普通按钮保持设计高度并锚定所属区域上下边；正文承载剩余高度，文字组仍按原间距紧凑排列。
下面“明确高度”指参考容量核算；正文输出优先用 layoutWeight，填充宽度用 matchParent，
不把参考画布数值当成未知宿主的固定尺寸。背板内已有 8 或 12 的 padding 均保持原值。

1. 以已接受的 Compact Info Plan 为信息硬合同，按 2.6 节形成信息分区、关系、主次与动作归属清单；`componentHints` 与 `layoutHints` 只是软候选，不冻结具体实现；再按 2.4 节给事件标注 `explicit/implicit/sideEffect`，按 2.5 节独立裁决素材。2x2 选择骨架前按允许位置、数量和区域互斥确定图标，内容区只保留环中心或 `S-dual-info` 双业务主视觉图标，不为标题或文字信息行配图；2x4 沿用原素材选择规则。模型不直接生成独立图片，所有图标必须通过已登记组件的素材属性进入，并保持视觉 Recipe 的内部几何。
2. 严格采用 TaskSpec.size，按第九节选择正式布局。先为全部 `mustKeep` 预留可见空间，再分配字号与留白；必要事实与动作不能为了套用 Few-shot 或特定组件而消失。空间不足先去掉可选装饰、弱字段，再改用紧凑组合或同尺寸布局。
3. 为布局填入角色槽位。按语义、数据类型和展开后容量直接选择组件；候选不适配时改选能保留完整信息的其它组件或组件组合，不改写视觉 Recipe 的内部样式。单业务内容组按真实主辅关系分配高度：稀疏信息可在内容区居中，密集信息从上向下排列，动作沉底；等高分区不是默认要求。同级短数值可等宽并列，长值和带长单位的值改为纵向标签—值行。显式动作落到合法 CTA；整块点击仅在组件合同允许且目标归属正确时使用，不复制入口。
4. 从 root 到叶子递归计算父子宽高、padding、margin、有效 itemMargin、文本空间和点击热区；包含 layoutWeight/flexShrink 的正文也按全部后代行高计算，不能把它当零高度。先扣标题、动作和间距，算清正文参考容量，再用 layoutWeight 表达正文承载区的剩余空间关系，不把容量数值写回固定高度。任何负剩余空间、单位裁切风险或过小热区都触发删除可选装饰或布局回退，不删除 Plan 项。
5. 按第十二节先处理用户明确的配色要求，再判断融球条件，不满足时按业务选择固定浅色微渐变；内容、按钮和背板跟随选定背景的固定配色。为素材确定职责，保留多色图标和真实状态色例外，禁止使用纯色背板或自由取色。
6. 构造完整首帧 DataModel 和组件树，验证组件引用、可达性、动态路径、类型、Expression、模板和事件闭环；选中的动态字段不得用静态 sampleValue 替代绑定。
7. 按 2.6.6 复查动作归属，并逐项对照 `mustKeep` 与可见内容：数据行存在不等于卡面已经展示，存在事件候选也不等于已经生成必要入口。所选动态值必须出现在可见文本或对应图表中，进度组件不代替完整读数。再检查图标职责并输出极简协议 JSONL；失败时只删除弱内容、减少表面或回退布局，不突破协议和 TaskSpec 边界。
8. 最后分别验收“固定量”和“承载区”：固定标题、按钮、字号、图标和间距不放大；正文承载区逐层使用
   剩余参考预算并闭合，不能把仅够文字的高度误当成整个承载区高度。对每个底部普通按钮向上检查：
   同父正文是否承担剩余高度，多个固定事实组是否包在正文承载区内；不能只有背板伸展而按钮仍跟在
   固定事实组后面。无底部动作或固定槽不强套此结构。再逐项检查时间无重复、枚举含义
   不靠猜测、短值标签可辨识、按钮与作用对象同区。检查未通过时修正组织方式，不用机型尺寸特判补救。
