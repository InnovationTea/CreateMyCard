# 编辑设计原则

先满足明确修改 → 保留内容和行为 → 保证可读 → 维持对齐、留白、层次和色彩协调。
这些原则不授权改变受保护区域，也不是首次创建的固定字号、布局或配色模板。

## 局部排版

- “大一点/小一点”以当前字号为参照做适度调整，增减方向必须成立；不是套用某个默认字号。
- 字号、字重和长文案联动检查：文字自身固定宽高、自适应字号上下限、行数、父级高度、
  上层 maxHeight/minHeight、相邻区域及原点击热区。只授权确实需要调整的节点。
- 优先放宽不必要的固定承载、合理换行或重排；不通过删单位、截断主要事实或减小其它关键字
  来满足局部放大。fp 与 vp 不直接作为真机裁切结论，需要留有余量并等待实际视口复核。
- 不能只把 maxLines 调小或设 ellipsis 就认为变得简洁，动态值还要考虑比首帧更长的情况。

## 配色和整体风格

- 区分背景、面板、主文字、辅助文字、强调/进度和图标色。改整体色系时保持前景背景分离，
  协调原有透明度与渐变，位图和品牌标识保留原色，不把所有角色涂成同一色。
- 精确色号优先。只要求背景换色时优先保留原有前景；出现可读性问题才计划最小必要前景联动。
- “简约”可减少装饰、统一间距和圆角；“柔和”可降低背景饱和度并保持清晰文字；
  “科技感”可采用克制的冷色和清晰分组。风格词是方向，不自动授权删除内容、改文案或新增素材。
- 优先沿用已有视觉关系，选择少量一致变化；不无依据同时改变所有字重、对齐、阴影与圆角。
  保留信息主辅，不让装饰抢过关键数值或必要按钮。

## 尺寸变化与连续编辑

- 在未知视口下使用 matchParent、合理权重及内容驱动的排列，不假设机型或规格的像素宽高。
- 2x4 改 2x2 时保留原信息和动作，优先重组排列、压缩不必要留白并调整承载分配；
  不把整个卡片的字号、图标和间距同比缩小。2x2 改 2x4 时适度展开，避免夸大字号或无意义拉伸。
- 仅在计划授予的范围内重排；不把“整体风格”误认为“重新设计内容”。
- 基于本轮 previousGenui 保留此前已完成的修改，修复也只以该原卡为基线，不叠加失败结果。
  当前信息不足以恢复历史值时澄清；不凭用户说“之前”就猜一个默认值。
