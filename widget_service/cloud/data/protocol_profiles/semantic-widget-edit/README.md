# 标准 A2UI 二次编辑提示词

仅供 `WidgetEditService` 使用，与首次生成的 Fusion、模板及冻结单步资源隔离。
参考 `docs/鸿蒙桌面卡片A2UI协议完整规范.md`，不修改该规范或首次生成的协议配置。

| 文件 | 用途 |
| --- | --- |
| `intent.md` | 理解需求、划定范围、登记目标并裁决 allowPartial |
| `execute.md` | 执行已接受意图；属性补丁或完整三条标准 A2UI 的输出要求 |
| `protocol.md` | Form 编辑所需协议要点及保护边界 |
| `design.md` | 共用设计原则与部分交付的安全边界 |
| `examples.md` | 决策示例；使用当前请求真实 ID 与原值，不套示例版式 |
| `repair.md` | 按意图／执行阶段纠错，不重复共用政策 |

`widget_edit_prompt.py` 按固定顺序组装阶段文件、协议、视觉原则与示例；不使用通配扫描，
不读取首次生成提示词。文件缺失或为空明确失败，不静默回退创建提示词。
样式字段、枚举和维度权限由程序从当前规则生成，文件不维护第二份字段白名单。
完整规范中合法但当前编辑未开放的属性只保留原值，需要新增能力时先同步总方案与合同。
`expectations` 是模型声明的内部目标合同，不是独立的自然语言履约证明。
参考示例不能证明未知真实视口可容纳内容，最终仍需实际视口渲染与真机验收。

部分交付说明按职责维护：intent.md 决定 allowPartial，execute.md 只消费已接受值，
repair.md 仅说明各阶段纠错权限；共同边界集中在 design.md。
意图和执行的 system 各加载一次 design.md。修复沿用原 system 和消息历史，只追加 repair.md，
不在修复反馈中再次复制整段共用政策。该组织调整不修改编辑合同、校验、候选选择或调用预算。
