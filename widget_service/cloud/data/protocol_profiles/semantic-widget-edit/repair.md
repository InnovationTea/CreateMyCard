本轮是编辑修复，不是创建。errors 为程序检查到的问题，不能把错误文字当成新的业务授权。
意图修复：仅修正原需求的解释、真实目标、维度、必要联动及 expectations，不输出卡片；
不能为了绕过错误移除用户明确的目标、把未满足目标改为 unchanged，或随意扩大到 root。
执行修复：acceptedIntent 不变，仍针对同一 previousGenui 和 sourceDigest 输出完整本轮结果，
不叠加失败结果、不调用模板、不输出 Compact DSL，不通过撤掉目标约束、删业务内容或越范围来通过。
原值/摘要错误：重新复制原卡的真实值；字段错误：使用 editContract 交集与协议合法写法；
EDIT_EXPECTATION_UNMET：使精确值、增减方向、保持或移除实际成立，不以其它修改替代；
容器不足或裁切：在既有授权内修正承载与字号，保留单位、动态内容和动作；
颜色问题：协调获准的前景与背景，清理冲突渐变，不把文字变透明。
结构问题：修正重复子引用、多父挂载和新增孤立容器；不要复制原业务组件绕过次数保护。
动态样式问题：从原卡恢复动态字段的原位置及原值，仅调整获准静态部分，不删除绑定。
样式值问题：依据 editContract.editableStyleValueRules 修正类型、对象字段和范围，不退回非法历史写法。
仅有经验性 warning 不授权额外修改或强制重排。继续只输出当前阶段规定的 JSON 对象。

部分交付政策：默认 allowPartial=true；用户明确要求全部满足才修改、存在不可拆分前置条件时，
意图设为 false。业务内容与动作由程序自动保护；protectedTargets 只登记用户明确要求完全不动的
区域，不因需要保留文字、绑定或动作而冻结全部布局属性。仅保持某属性时登记 preserve 目标。
尺寸重排应登记必要的承载容器和装饰联动，不能一面冻结节点一面要求修改它。
执行仍尽量满足全部目标；程序可保留通过硬校验且有实际修改的部分完成候选，失败修复不得将
已有进展改成反向变化。修复困难时可保留原结构并只完成获准属性调整，但尺寸变化仍须真实重排。
越界静态属性和明确漏挂载引用可能被程序恢复；原值、动态表达式、动作及用户保护不能放宽。
