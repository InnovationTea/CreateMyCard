# 极简 DSL 渲染器启动说明

本工具位于 CreateMyCard 仓库根目录下的 `render/`。以下假设仓库克隆在 `C:\path\CreateMyCard`，工具目录为 `C:\path\CreateMyCard\render`。以下命令在 Windows PowerShell 中执行；若项目放在其他位置，请替换路径。

这是本地渲染器：极简 DSL → A2UI → 卡片预览。无需配置 LLM、API Key、数据库或单独的后端服务，示例和图标已包含在项目中。

## 1. 首次安装依赖

先安装 Node.js（可使用 22.x）及随附的 npm，确认命令可用：

```powershell
node --version
npm --version
```

两个目录的依赖都需要安装：

```powershell
Set-Location C:\path\CreateMyCard\render\genui-sdk
npm ci

Set-Location C:\path\CreateMyCard\render\platform
npm ci
```

每一步成功后再执行下一步。安装依赖需要网络；已安装且锁文件未变化时，无需每次重新安装。

## 2. 日常开发启动

```powershell
Set-Location C:\path\CreateMyCard\render\platform
npm run dev
```

终端出现 Ready 后打开：**http://127.0.0.1:3000/**。

保持终端运行，修改代码后页面自动更新。在该终端按 `Ctrl + C` 停止服务。

## 3. 生产模式运行

先停止正在运行的开发服务，再构建并启动：

```powershell
Set-Location C:\path\CreateMyCard\render\platform
npm run build
# 构建成功后执行：
npm start
```

同样访问 **http://127.0.0.1:3000/**。代码修改后需要停止服务，重新 build，再 start。开发模式与生产模式任选一种，不要在同一项目目录同时运行或构建。

平台直接编译 SDK 源码，无需提前运行 `genui-sdk` 的 build。

## 4. 页面使用

1. 从“示例”选择卡片，或在左侧粘贴极简 DSL。
2. 点击“渲染预览”，也可按 `Ctrl + Enter`。
3. 右侧查看卡片，可调整预览宽高；切换“A2UI”查看转换结果。
4. 点击卡片动作后，页面显示解析后的事件参数。Intent 和 Deeplink 不会实际执行，需另接宿主实现。

内置 30 个分支示例和原始发布会倒计时示例。个别示例的尺寸、素材兼容处理见 [兼容说明](docs/fusion-compatibility.md)。

## 5. 常见问题

### 端口 3000 被占用（EADDRINUSE）

当前可能已经有服务在运行，先访问页面确认。若要停止，在原服务终端按 `Ctrl + C`。

若服务在后台运行，可先查明占用进程：

```powershell
$listeners = Get-NetTCPConnection -LocalPort 3000 -State Listen -ErrorAction SilentlyContinue
$listeners | Select-Object LocalAddress, LocalPort, OwningProcess
$listeners | ForEach-Object { Get-CimInstance Win32_Process -Filter "ProcessId = $($_.OwningProcess)" } |
  Select-Object ProcessId, CommandLine
```

确认命令行属于本项目后，用查到的实际 PID 停止，再重新启动：

```powershell
# 将 12345 替换为确认过的本项目进程 PID
Stop-Process -Id 12345
```

不要直接关闭全部 Node.js 进程，以免影响其他项目。

### npm.ps1 无法执行

如果 PowerShell 的脚本策略阻止 npm，使用 `npm.cmd`，例如 `npm.cmd ci`、`npm.cmd run dev`，无需修改系统策略。

### 找不到模块或 tsx

重新检查 `genui-sdk` 和 `platform` 两个目录是否都成功执行了 `npm ci`。若更新了代码和依赖锁文件，也需要重新安装。

### npm start 提示找不到生产构建

先执行 `npm run build`，确认成功后再 `npm start`；开发时直接用 `npm run dev`。

### 重启后页面仍显示旧样式

刷新页面（必要时按 `Ctrl + F5`）。生产模式下确认已完成重新构建和重启。

## 6. 验证代码

在 `platform` 目录执行：

```powershell
npm test
npx tsc --noEmit --incremental false
```

测试使用本地数据，不会调用 LLM。生产构建命令为 `npm run build`。
