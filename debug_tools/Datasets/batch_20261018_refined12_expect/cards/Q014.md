# Q014 · 设备充电（精致版期望输出）

> 身份：**期望输出**，供「导入期望输出」页手工录入。底稿是批跑 `batch_20261018_160124_3f440556` 里同 ID 的模型 DSL，入参（Query、候选字段、候选事件、候选素材、声明尺寸）完全沿用，只重做了版式与信息层次。

## 卡片信息

- Query：帮我做个充电状态卡片，看手机是否在充电、使用的充电器类型和耳机仓是否在充电，点一下打开电池设置。
- 尺寸：2x2（与入参一致，root 用 S- 系列布局）
- 布局：S-title-primary-secondary-action
- 版面验算：展开后纵向实算 122vp／预算 126vp（几何取自 `convert_compact_dsl_to_a2ui` 展开的 `styles.height`、`padding`、`itemMargin`）
- 分类：设备（导入页可按这个分类建组）
- 已通过 `convert_compact_dsl_to_a2ui` 严格转换，可直接贴进「卡片渲染」页预览。

## 比批跑原文精致在哪

- 标题让出图标位，按钮改用带闪电图标的动作，动作图标优先于标题图标。
- 入参候选字段 3 项，本卡实算命中 3 项；批跑原文实算 3 项。
- 图标实例 1 个（2x2 预算上限 2 个）。
