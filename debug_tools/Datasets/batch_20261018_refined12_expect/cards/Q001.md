# Q001 · 西湖天气（精致版期望输出）

> 身份：**期望输出**，供「导入期望输出」页手工录入。底稿是批跑 `batch_20261018_160124_3f440556` 里同 ID 的模型 DSL，入参（Query、候选字段、候选事件、候选素材、声明尺寸）完全沿用，只重做了版式与信息层次。

## 卡片信息

- Query：帮我做个卡片，看杭州市西湖区现在是什么天气，点一下查看杭州天气详情。
- 尺寸：2x2（与入参一致，root 用 S- 系列布局）
- 布局：S-title-primary-secondary-action
- 版面验算：展开后纵向实算 112vp／预算 126vp（几何取自 `convert_compact_dsl_to_a2ui` 展开的 `styles.height`、`padding`、`itemMargin`）
- 分类：天气（导入页可按这个分类建组）
- 已通过 `convert_compact_dsl_to_a2ui` 严格转换，可直接贴进「卡片渲染」页预览。

## 比批跑原文精致在哪

- `S-title-content-action`（只有天气现象＋城市码两绑）改为 `S-title-primary-secondary-action`：区名与市名进支撑行，核心读数与动作分层。
- 入参候选字段 4 项，本卡实算命中 4 项；批跑原文实算 2 项。
- 图标实例 1 个（2x2 预算上限 2 个）。
