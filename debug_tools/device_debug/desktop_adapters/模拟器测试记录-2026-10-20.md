## 发现与修复

1. 重复保存完整 DSL 时，`mkdirSync` 对已有目录报 `File exists`，使第二轮提交失败。
   已在创建前检查目录是否存在；修复后实际连续提交 3 轮通过。
2. HDC 系统语言参数为空导致简体中文环境被拒绝。现改用 LocalizationKit 回传系统语言，
   Python 回归覆盖两种中文值、英文和缺失值。
3. 桌面命令失败现保留并显示系统错误码，便于区分查询失败和其它设备异常。

零实例问题尚未修复：未加桌、删除最后一张卡片后，`getPublishedRunningFormInfos` 报
`16500100 / Failed to obtain the configuration information.`；选择器中存在临时预览，或已有
实际桌面实例时，接口可返回列表。旧的 `getPublishedFormInfos` 在零实例状态同样报错，
读取静态配置也不能解决。未把该错误转换为空列表；规格切换仍在此处停止。

连续拖拽问题尚未修复：UiTest CLI 的直线拖动能移动本应用入口，但未创建新页；本轮尝试的
选择器拖动没有退出选择器并完成加桌。尚需验证带边缘停留和分段路径的 UiTest 手势，再实现对应
动作及适配器。未用自动选址替代生产认证。
