# 登记图片素材同步记录

日期：2026-10-17。

以 `widget_service/cloud/data/capabilities/app-11.7.7.300_rom-7.0/asset_capabilities.json`
登记的 141 张图片为范围，从仓库根目录 `resources/base/media/` 原样复制。
浏览器沿用 `render/platform/public/resources/base/media/`，由调试平台资源路由和 Vite 读取；

本次浏览器新增 32 张、更新 1 张，真机工程新增 74 张、更新 1 张，合计变更 108 个图片文件。
保留文件名大小写及清单外工程资源。未修改云侧能力清单、源图片或 `widget_service/tests`。
工作区原有的 `debug_tools/a2ui_render/oh-package-lock.json5` 和 `debug_tools/device_config.yaml`
不属于本次变更。

## 验证结果

- 同步检查：两端各 141 张，合计 282 次文件摘要对照全部通过，缺失和内容差异均为 0。
- 图片完整性：106 个 SVG XML 解析、35 张位图 Pillow 校验全部通过。
- 浏览器资源接口：141 次请求全部返回 HTTP 200，响应摘要与源文件一致。
- 真机工程：本地 HAP 构建成功，包内 141 张登记图片均存在且摘要与源文件一致；未部署至设备。
- Ruff：`debug_tools/scripts/sync_assets.py` 检查通过。
- 单元测试：`test_asset_url_mapper.py` 和 `test_debug_device_capture.py` 共 61 项通过，
  无失败；有一条既有 Starlette 弃用提示。
- `git diff --check`（暂存前已跟踪文件）：通过。完整暂存区检查发现两端的
  `ic_calender.svg` 第 8 行、`ic_sun_monochrome.svg` 第 2 行共 4 处源文件既有行尾空白；
  为保持登记素材字节一致而原样保留，其余文件检查通过。

HAP 位于 `debug_tools/a2ui_render/entry/build/default/outputs/default/entry-default-unsigned.hap`，

这些构建和测试输出不纳入源码变更。
