# 批量测试

`batch_testing` 为调试工作台提供持久化任务中心、单消费者执行队列、逐样本结果、Trace 解析和后处理调度。
批跑由 Python 后端执行，关闭浏览器不会中断任务。

## 数据集

数据集放在 `debug_tools/Datasets/<dataset>/`。任务创建页只扫描 `Datasets` 的直接子目录，并读取其中的
有效 JSON 文件，不递归扫描更深层目录。

创建任务时可以：

- 选择一个数据集及其中任意样本；
- 设置公共请求字段覆盖；
- 选择“已部署”或“本地受管”后端；
- 调整页面允许暴露的非敏感模型测试参数。

任务保存的是样本选择和配置快照，不修改源数据文件。创建任务后会立即生成首个执行并加入队列，无需再次
点击启动。

## 任务与队列

- 全局同一时刻只执行一个批跑任务；任务内部可以并发处理样本。
- 再次执行同一任务会生成新的独立运行结果。
- 调试后端重启时，正在执行的运行会标记为中断，等待队列保持暂停，需要用户显式恢复。
- 停止、失败或单样本错误不会覆盖历史运行。

任务的并发数、额外失败重试、调用超时、服务启动超时和 Trace 根目录统一读取
`end_to_end_debug/backend/debug_agent.yaml` 的 `batch_testing` 节，不在创建任务页重复配置。

## 后端模式

### 已部署

直接连接任务中保存的 `ws://` 或 `wss://` 微服务地址。平台不启动也不回收该服务。

### 本地受管

调试后端根据稳定配置和任务中的模型测试参数启动本地微服务，自动选择回环空闲端口，并负责探活和回收。
敏感配置只从 `.env` 或进程环境继承，不下发浏览器，也不写入任务快照。

平台只会终止自己启动且能够通过进程标识、创建时间和启动命令共同确认的进程。队列空闲后，受管服务会被
关闭；有效配置相同时，相邻任务可复用同一服务。

## 结果目录

每次运行写入：

```text
debug_tools/batch_output/<runId>/
├── manifest.json
├── summary.json
├── summary.md
├── trace_blob_manifest.json
├── trace_blobs/
├── samples/
└── postprocess/
```

每个样本保存请求、终态响应、artifact blocks、`genui.jsonl`、最终结果和各 attempt 的 Trace。运行级
`trace_blobs/` 按 SHA-256 去重附件；读取时会校验字节数和摘要。

不要手工依赖未在本 README 中承诺的内部文件层级。需要消费结果时，优先使用页面 API 或稳定的
`manifest.json`、`summary.json`。

## Trace

任务详情可以从单样本入口在新标签页打开 Trace。页面提供：

- attempt 切换；
- 阶段树和时间瀑布；
- 输入、输出、诊断与快照附件；
- 原始记录查看。

新运行只接受 `generation-trace-v2`。Trace 缺失、未完成、结构错误或附件校验失败只显示告警，不会把已经
成功生成的样本改判为失败。任务详情和画廊使用相同的卡片尺寸解析规则：优先最终 CardSpec，其次 query 中
的明确尺寸，再回退到样本尺寸。

## 后处理

批跑完成后不会自动执行后处理。用户在任务详情选择插件并点击“开始后处理”：

- 依赖插件由宿主自动补齐；
- 没有依赖关系的插件可以并行执行；
- 已有执行历史的插件不会被普通启动重复运行；
- 点击“再次运行”会创建新历史，不覆盖旧结果；
- 单样本或单插件失败不改变原批跑业务状态。

内置插件包括浏览器渲染画廊、真机截图画廊和组件召回分析。插件清单、输出类型、依赖和开发接口见
[`../postprocess_plugins/README.md`](../postprocess_plugins/README.md)。

## 真机截图配置

真机截图在批跑完成后作为独立后处理插件运行。HDC、DevEco、ArkTS 渲染工程、签名 HAP、设备和裁切配置
统一位于 `end_to_end_debug/backend/debug_agent.yaml` 的 `device_capture` 节；这些字段不进入微服务配置、
任务快照或浏览器响应。

未设置设备 SN 时必须且只能连接一台 HDC 设备。配置、构建、设备或截图失败只记入插件结果，不改变批跑
状态。浏览器画廊与真机截图默认没有依赖关系，可以并行运行。

## 主要模块

| 文件 | 职责 |
| --- | --- |
| `api.py` | 批量测试 HTTP API 注册 |
| `task_manager.py` | 任务、运行记录和持久化队列 |
| `runner.py` | 样本执行和结果保存 |
| `service_manager.py` | 本地受管微服务生命周期 |
| `trace_parser.py`、`trace_view.py` | Trace 导入、校验和页面视图模型 |
| `postprocess.py` | 插件发现、依赖调度和执行历史 |
| `gallery.py` | 浏览器渲染画廊 |
| `device_capture.py` | 真机截图编排 |

工作台启动和页面操作见 [`../README.md`](../README.md)。
